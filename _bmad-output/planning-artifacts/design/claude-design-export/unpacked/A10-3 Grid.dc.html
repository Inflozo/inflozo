Grid

Four, five or six stats in a matrix of shared hairlines. The design 1 Row, 2 Cards, 7 Contrast Band and 14 Change all hand off to when a fifth stat is authored, and the only one in A10 where settlement 1's rule for five is drawn rather than described.

A grid of six is 2 Cards with the card edges shared, which is what makes it hold twice the content in the same width: one hairline between two cells instead of two edges and a gutter. It is also the design that most looks like a table and most carefully is not one — no header row, no column that means anything down its length, and nothing to compare.

Five is 3 + 2, the second row keeping the 432 cell width and sitting at the left — settlement 1, drawn here for the only time in A10. The sixth cell is absent, and its hairlines are absent with it: no rule to the right of the fifth cell and no rule under an empty space, because a hairline around nothing is a cell a reader looks into. At Count Four, Columns Three is unavailable and the control says “Two at four stats”. 3 + 1 puts one cell alone beside two cell-widths of nothing, which is worse than five's 3 + 2 by exactly one empty cell. Five in two columns is 2 + 2 + 1 and is allowed, because a column of pairs ending in a single reads as a list that ran out rather than a grid with a hole in it. ⚑ Mine. Frame Boxed draws an outer hairline at the pack radius with surface inside it and keeps the outer padding, which makes the block an object on the page instead of a division of it. No shadow at either value, and the internal hairlines are the same weight and colour as the outer one — a heavier frame around lighter divisions is a table's border, and this is not a table.

A 60-CHARACTER LABEL AND A MISSING ONE IN THE SAME ROW · THE ROW'S HEIGHT IS THE TALLEST CELL'S, THE HAIRLINES RUN ITS FULL HEIGHT
A row's cells are one height because a shared hairline has to run somewhere, and a rule that stops halfway down a row is the defect this design would otherwise have. The values still sit on one baseline per row and the slack falls at the foot of the short cells, exactly as in 1 Row. A 60-character label is two lines at 432 px and sets the row's height; the labelless cell beside it is a value with a hairline running past it. It is not a <table>, and this is the design that had to say so. There is no header row. Nothing in column two relates to anything else in column two. A table would promise a reader that the columns can be read down their length, and would hand a screen reader “row 2, column 3” coordinates for a set that has no coordinates. It is a <ul> of six <li> in a CSS grid, read in authored order. ⚑ A10-0's refusal, drawn here. Value size stops at Large 52 in this design. Display 68 in a six-cell matrix is six display moments, and §2 allows one per section — the grid's job is to hold more numbers, not louder ones. The control shows two values and says so.

ACCESSIBILITY · THE DESIGN THAT LOOKS MOST LIKE A TABLE A <ul> of six <li> in a CSS grid, each <li> one <p>. Not a <table>, not a <dl>, no role="grid" and no aria-rowindex. A screen reader hears “list of six” and then six stats in authored order, which is the whole content: there are no coordinates to report because a cell's position carries no meaning. The reading order is the authored order at all three widths, and the number of columns changes nothing about it. The absent sixth cell at Count Five is an absent <li>, not an empty one — at Frame Boxed it is a decorative <div> holding the block's corner and carrying aria-hidden, which is the only aria-hidden element in the design. ⚑ Mine. The hairlines are border on the cells, never <hr> and never a background gradient, so forced colours keeps the whole matrix: the grid is the one design in A10 that reads identically with the system's own colours, because its structure is made of borders rather than of fills or spacing. Contrast: value 15.8:1 light / 15.1:1 dark, label 5.6:1 / 6.0:1, hairline 1.3:1 on the ground and 1.5:1 on a boxed block. One tab stop at most — the link. No behaviour, no state, no hover. Print: the whole matrix prints, Boxed included.
