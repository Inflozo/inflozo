A10 STATS AND NUMBERS · DESIGN 1 OF 15 · PAPER PACK · THE DEFAULT · SEVEN CONTROLS

Row

Two, three or four stats side by side across the 1,296 content width, hairlines in the gutters, values on one baseline. The design a site gets when it types “stats” into the picker, the one A10-0's stat component was drawn for, and the design seven others hand off to.

It is also the only design in A10 that carries seven controls — §7.6's ceiling — because it is the design where all four of §8's settlements are visible at once: the count, the units, the source line and what happens to a cell with no label. Everything else in the category is a rearrangement of this row, and every rule it establishes is cited rather than restated fourteen times.

Two hover states and two focus rings in the whole design, and both belong to links. There is no state on a stat: no hover plane, no cursor change, no underline, no lift. A number that responds to a pointer is a number a reader will try to press. The source line becomes a link when sourceUrl is authored, and takes text rather than text-muted when it does — a muted link at 13 px with an accent underline is 4.9:1 on the underline and 5.6:1 on the text, and a link should not be the quietest thing on the frame. ⚑ Mine. ACCESSIBILITY · A SECTION WITH NOTHING TO OPERATE <section aria-labelledby> named by the title, an <h2>; the row a <ul> of three <li>; each stat one <p>. The value and the label are two <span>s in one paragraph, so the announcement is “41,800 readers on the Thursday letter” and not two fragments a reader has to join. The value is not a heading at any size, and the label is not an <abbr>, a <dt> or a caption. The prefix and the suffix are read as part of the value because they are inline spans in the same run: “62%” is announced as sixty-two per cent by every screen reader tested against a plain percent sign. A word suffix is announced as written — “3.4 hrs” is read “three point four hrs”, which is why the field takes what the site types rather than an abbreviation the theme expands. ⚑ Flagged: no aria-label is written over a value, because a label that says “3.4 hours” while the page says “3.4 hrs” is two different sections. One tab stop at most: the link. With no link and no source URL authored the section contains nothing focusable at all — no tab stop, no role, no live region, no state to announce. The dividers are decorative border on a <div>, never <hr>. Contrast: value 15.8:1 light / 15.1:1 dark, label 5.6:1 / 6.0:1, divider 1.3:1 (decorative), link text 15.8:1 / 15.1:1 with the underline at 3.3:1 / 6.3:1, focus ring 3.3:1 / 6.3:1. In forced colours the dividers survive as system borders and the label stops being quieter than the value, which flattens the hierarchy to size alone — stated, not corrected. Print and screen are the same drawing. Reduced motion changes nothing, because nothing moves. The only transition in the design is the link underline's 160 ms thickening, which is instant under reduced motion and does not change what the link is.
