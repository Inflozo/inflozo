A three-up grid that grows in place under one button. The only design in A17 where pagination appears inside the section — and, per settlement 4, it appears there only with JavaScript switched off.

It declares load-more, whose registry line is unusually specific: “Ghost's numbered /page/2/ pagination links render instead (FR-G4, explicitly).” So the button is not the navigation — it is an enhancement over navigation that already exists, and the no-JS state on this page is a real page rather than a fallback sketch.

Its interesting problem is what the button says, and what happens when there is nothing left. A control that promises more and then dies is worse than a link that always told the truth, so this design counts — and the panel settles what it counts and when it stops.

The grid is 1 Three Up and the button is the whole design. Same cells, same gutter, same card — what this design adds is a batch boundary and something to cross it with.
The button is centred, and it is the only section-level element in A17 that is not flush left. (Tag plates centre their labels inside themselves, per settlement 2 — that is an item's interior, not the section's axis.) Every other section-level element in the category sits on the left edge of the content column; a control that acts on the grid as a whole belongs under its middle, and a left-aligned button under a three-column grid reads as belonging to the first column. ⚑ Mine, and a deliberate exception to the category's alignment.
It says “Load 6 more”, not “Load more” — the number is the batch size, so the button states exactly what pressing it does. “Showing 6 of 12” sits beneath it, which is what makes the button honest: a reader sees how much is left before committing to a click. Both strings are composed from data rather than authored, so neither is a content field.
48 px between the grid and the button, 16 between button and count. Outline is the default: a 1 px text-coloured hairline on a 24 px radius, 13 × 30 padding — measured 45 px tall, above the 44 px touch minimum, unlike 15 Filtered's 33 px pills.

No spinner, and the button is not disabled while loading. “Load 6 more” becomes “Loading…”, border and label go muted, and the control keeps its focus ring — a disabled button drops out of the tab order and a keyboard user loses their place mid-action. ⚑ Mine. A17-0 permits no motion here and none is needed: a batch arrives in one paint. Exhausted replaces the button with a line of text rather than greying it out. “That's all 12 posts.” A dead control left on the page is a lie about what is available, and a greyed button invites a second click. The line is composed from the count, not authored — which is deliberate: an authored string would drift out of date against a growing archive, and a counted one cannot. The no-JS state is not a degradation, it is Ghost's own pagination, and the registry says so explicitly. That makes this the one design in A17 whose no-JS state is worth drawing — everywhere else the answer is “identical”. The numbered links are A34's component, inherited rather than designed here, and the button is simply absent rather than replaced in place.
