Six photographs in three even columns on the page ground, every frame cropped to the same ratio, each caption under its own frame. The category default and the arrangement six other designs resolve to at 390.

WHAT THE GRID SETTLES FOR THE CATEGORY
Crop is enforced by default, and “As uploaded” is one value of the control ⚑ — settlement 2. Four values: Square 1:1 · Landscape 4:3 · Portrait 3:4 · As uploaded. Everything but the last sets one aspect-ratio on every cell and covers; the focal point is a field on the image, not a control ⚑, because where a picture is cropped is content.A14 has no Show ladder ⚑ — A17's 3 · 6 · 9 · 12 and A19's 1 · 2 · 3 · 5 count a query, and there is no query here. The count is the length of the list, so every design's arrangement has to hold at whatever the user typed.Radius is never a control ⚑ — it is the pack's token, taken by the frame, the lightbox and the card together, and mixing two radii in one gallery is the single fastest way to make it look wrong.

At one image the cell keeps its column width and does not stretch ⚑ — a photograph blown to 1,296 is 10 Lead and Grid, and the panel names it. A caption left empty shortens its own figure and moves nothing else ⚑ — the frames are the same height, the row is set by the tallest figure, and the grid does not re-align. alt is not the caption and the caption is not alt ⚑ — separate fields, separate jobs. A frame with a caption and no alt gets alt="" and aria-hidden on the image, with the caption doing the describing in the flow; the editor marks the image with a warning dot and never blocks publishing ⚑.

One overlay, fifteen designs ⚑ — every design's Lightbox control writes the same value and gets the same overlay, and no design has an overlay of its own. No-JS, quoted: “Each thumbnail is an <a href> to the full-size image; clicking opens it as a normal page.” Which A14 satisfies by construction: the frame is an <a href> to the original file before any script runs, so with JavaScript off the gallery is a set of links to full-size photographs. An image carrying its own link is never a lightbox trigger ⚑ — the author's link wins, and the panel says so.
