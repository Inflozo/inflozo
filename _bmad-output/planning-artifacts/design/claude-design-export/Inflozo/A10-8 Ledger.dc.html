Ledger

The label at the left, the value right-aligned in a 300 px column, hairline rows between them — A9·15's geometry holding figures instead of prose. The design for six long labels, and the only one in A10 where the value is not the first thing in its row.

Settlement 4 put the value first in fourteen designs so that a missing label costs nothing. Here the label is first and the trade is deliberate: six labels of sixty characters each is a list a reader scans down the left, and six values right-aligned in one column is where tabular figures do the most work in the whole category — the digits line up, so the numbers can be compared at a glance without being a table.

Widening the value column would not make the numbers bigger; widening the label column past 620 would break §2's reading measure. The label and the value sit on one baseline — align-items: baseline, so a 15 px label aligns to the foot of a 52 px numeral rather than to its top — which is the alignment that makes a row read as one statement.
The values are right-aligned and the figures are tabular, so their digits line up down the column. 41,800 · 62% · 340 · 74 end on the same vertical, and the hundreds column of one number sits over the hundreds column of the next. No leader dots — a row of dots between a label and a figure is a menu or a table of contents — and no decimal alignment, because the value is a text field and there is nothing dependable to align on. ⚑ Mine: the baseline alignment, right-aligned values and both refusals.

A 60-CHARACTER LABEL, AND A ROW WITH NO LABEL WHERE THE VALUE MOVES TO THE LEFT EDGE
A row with no label draws its value at the row's left edge, not at the right. This is the one rule A10 needed that no other design does: a value alone at the right of a 976 px row, with 620 px of nothing to its left, reads as a row whose label failed to load. At the left edge it reads as a figure without a caption, which is what it is. The other values keep their right alignment and the column is unbroken — one row starts differently, and nothing else moves. ⚑ Mine, and the only place in A10 where a missing field changes an element's position. A 60-character label is three lines on the 620 measure and the value stays on the first line's baseline — not the last's, and not centred against the block — so the value's own column keeps its rhythm however long the labels are. The row grows downward. ⚑ Mine. No total row, at any count. Ghost does no arithmetic and a total the site typed is just another stat, which it can author as one; a theme that summed the column would be claiming the six figures are addable, and “62%” plus “340” is not a number.

ACCESSIBILITY · THE DESIGN THAT MOST WANTS TO BE A TABLE A <ul> of <li>, each one <p> holding a label span and a value span in a flex row. Not a <table> — there is no header row and no column that can be read down its length as a series — and not a <dl>, A10-0's refusal, in the layout that most tempts one. A9·15 made both refusals for the same geometry holding prose. The reading order is label then value, which is the reverse of the other fourteen designs, and it is stated in the panel. It is the honest order here, because it is the drawn order; a design whose DOM said value-then-label while the page said the opposite would read correctly to nobody. The two orders are equally sound as announcements — “readers on the Thursday letter, 41,800” — and the difference is which the eye meets first. The right alignment is text-align on the value span and carries no meaning; a screen reader hears the same string whatever the alignment. Tabular figures are a font feature, not content. Contrast: value 15.8:1 light / 15.1:1 dark, label 5.6:1 / 6.0:1, hairline 1.3:1 / 2.3:1. One tab stop at most. In forced colours the hairlines survive and the label stops being quieter than the value, which in this design flattens the two into one weight — the rows are still divided, so the pairing survives. Print and screen are the same drawing.

STATS · the item list · outside the design’s listStats is the P0·3 item list: Add stat arrives with content — value 100, label “What this number counts” — Remove is never disabled, drag to reorder, per-item content only. Per item: value ≤ 12 · prefix ≤ 3 · suffix ≤ 6 · label ≤ 60. note, prev and share held. Value source: Authored · Member count · Paid member count. At Member count the value renders Ghost’s {​{total_members}} string verbatim — “1,200+” in, “1,200+” out, no maths and no formatter, which is the category’s own no-formatter rule — prefix and suffix are disabled and the label stays authored. {​{total_paid_members}} is offered only when the site has paid members enabled. Eight is the ceiling of stats[], raised from six in this pass: “Eight numbers is as many as a reader holds in one look. A ninth is a table, and a table is a different section.” 3 Grid is the only design that draws eight; everywhere else seven or eight authored names it. Seven or eight authored → 3 Grid; two authored draws two rows and the panel says the design is meant for three or more; one names 4 Single.
EDITING · the P0 primitivesValue, prefix, suffix and label edit inline on canvas, selected where they are drawn rather than only in the repeater. The value raises no marks toolbar — it is plain text, so bold, italic and a link inside a figure are withheld rather than offered and refused. Eyebrow, title, sub, source and the link label take the P0·1 toolbar — bold · italic · underline · link, the popover carrying open-in-new-tab and rel nofollow · noreferrer · sponsored. A value bound to a member count is not inline-editable: clicking it says “Edit in Ghost”, because the figure is the site’s member list and not a word anyone typed here. The value edits in place at the right of its row and stays right-aligned with tabular figures while it is being typed. sourceUrl and linkUrl open the Link Picker; the section link takes an optional P0·2 icon.
BEHAVIOUR · from the fixed registrycount-up, from the fixed registry, and only at Count up On. Its own degradation is the argument: “The final value renders as static text — it is already in the HTML before JS ever runs.” JS off, reduced motion and assistive technology all get the figure rather than the animation, and the module does not re-run on the way back up the page. Edit-safe: it does not run while the section is edited, so every frame here is still a resting state. At Count up Off — the default — this design declares no module at all: the rows are hairline borders, the shared baseline is align-items: baseline, the figures are right-aligned with tabular-nums, and the value moving under the label at 1080 is a media query. No sort, no filter and no column control is offered at any value.

They are reached from the item’s Value source and not from a “Populate from…” panel — there is no list to populate. Everything else is authored in this section.
