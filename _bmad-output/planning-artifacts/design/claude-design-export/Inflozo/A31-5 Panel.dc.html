There is no themed submitting state ⚑. The form is a native POST, so the browser owns the wait: the button keeps its resting look and the page navigates. A spinner would need a module the registry does not have — the closest is member-form, which posts to Ghost’s members endpoint and is the wrong endpoint. That is a finding, not a new module.Wrong password is a fresh server render ⚑, not an inline check: Ghost re-renders private.hbs with its own error, the field comes back empty — Ghost does not echo a password — and focus returns to the field. The message sits above the label so a screen reader meets it before the input.The message is Ghost’s string and not a field ⚑. A design decides where it sits and how it is marked, and no control changes its words. It is drawn in the text colour on the plate with a hairline, never in red: the Paper pack has no error token, and inventing one would break in the other eleven packs.

The message is above the label inside the plane, and the plane’s depth does not change ⚑. Nothing about a wrong password is a property of the container.

THE PAGE SOURCE · IDENTICAL IN ALL TEN · NOT COUNTED
Which page this is
From the status code🔒
Read-only. Ghost decides — error.hbs at a 404, the same file at a 500, private.hbs at /private/ ⚑ — and the section draws the matching copy set. One design, three pages.
What a 500 may ask Ghost for
Nothing🔒
Read-only. No {​{#get}​}, no navigation, no member state, no settings image ⚑ — a 500 may be the data layer failing, so every query is a second chance to fail. Static text, the site title and one link to /.
Navigation on this page
Set by the page🔒
Read-only. Full chrome on the 404 · title and one link on the 500 · none on the gate ⚑. A visitor at /private/ is not in the site yet, and nav labels describe a site they have not been admitted to.
Where the gate posts
Ghost’s /private/🔒
Read-only. A native POST to Ghost’s own route ⚑ — <form action="/private/?r={​{@path}​}" method="post">. The wrong-password message is Ghost’s string, not a field; the design decides only where it sits.
What search reaches
Title, excerpt and slug🔒
Read-only. A23’s index ⚑ — body text is not indexed. Search is offered on the 404 only: never on a 500 (the index is a request to the site that is failing) and never on the gate.
EDITING · THE P0 PRIMITIVESEvery authored string edits inline on canvas with the P0·1 toolbar — bold · italic · underline · link, the popover carrying Open in new tab and rel nofollow · noreferrer · sponsored: heading, blurb, eyebrow, both action labels, linksLabel, the search placeholder and the gate's field, button and helper strings. Ghost-owned content is never inline-editable ⚑ — the status code, Ghost's wrong-password string, post titles and excerpts, navigation labels and @site.title answer "Edit in Ghost" or show P0·1's lock pill. Every URL field opens the Ghost-aware Link Picker. The primary button takes the optional P0·2 icon — Before or After the label, always Small, always the label's colour, its Size and Colour rows hidden. No fixed English visitor-facing string ships: the rescued literals above are fields with defaults, and the search field's two system words are catalog strings. There is no Preview control in this panel ⚑ — the three pages are P0·6's switcher above the canvas, which is the editor's job and never a sidebar's.Member Visibility lands nowhere in A31 ⚑, and it is a judgement rather than an omission: none of the three pages is a page a publication shows one audience and hides from another — a 404 is a wrong URL, a 500 is a failure and the gate is the absence of a member state. The 404's signed-in pill is A1's header, not this section's, and P0·4's member-aware action editor never opens here. Recorded in the Reconciliation notes.

WHAT THIS PANEL SETTLESThe plane’s width is not a control ⚑ — it is the content box, and a control that narrowed it would make this 3 Card. Two designs, one difference, and no panel row may cross it.Panel height = Fill is offered and is discouraged in its own help text ⚑. It is the honest way to handle a value some publications will want on a 404 and nobody should use on the gate.Closest neighbours: 3 Card (same surface, narrower, on the page ground) and 2 Split Reason (same two-column reading, no plane). Recovery links = Under and Depth = Flat is the nearest this gets to 3, and it is still 1,296 wide.Reconciled. Seven controls with Eyebrow added. Background role is locked to Surface ⚑ with the reason shown — the plane is the design. Vertical spacing owns the page rhythm; Panel height stays this design's own row, and the link column's linksLabel still names the nav landmark.
