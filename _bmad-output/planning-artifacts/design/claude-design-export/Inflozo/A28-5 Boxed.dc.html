5 · Boxed

A hairline box round the whole section, with the head in a divided row at the top of it and the block inside the same 40 px inset. A border rather than a plane — the distinction A25·11 drew between box and card, and the reason this design and 3 Panel are two designs rather than one control.

It is the design for packs whose surface and background are close enough that a plane does not read. The box holds at every width and in both modes, because a hairline works on any ground.

DESIGN PATCH PASS · 29 AUGUST 2026 · WHAT CHANGED ON THIS FRAME, AND WHY
The count is drawn by Ghost's own script. {​{comment_count}​} renders a placeholder that Ghost's comments script fills, so with JavaScript off there is no number at all — not a zero, nothing ⚑. This design's no-JavaScript line is rewritten in the drawn spec below, and its accessible name no longer depends on the count. The comment box's colour is a setting inside Ghost. Inflozo does not change it, so the Block colour row is gone from the Data group and no design passes mode= any more. In its place a read-only row that links to the setting in Ghost ⚑. The box closes round one sentence. With JavaScript off the head row draws, the count in it does not, and the <noscript> line is what the box contains ⚑. The h2 is the head inside the head row; the count in that row is not part of the name. What did not change. The visual language, the type scale, the colour packs, the spacing system, every measure and this design's number. The sent, error and loading states on member forms still work — only the promise that they work without JavaScript was wrong.
