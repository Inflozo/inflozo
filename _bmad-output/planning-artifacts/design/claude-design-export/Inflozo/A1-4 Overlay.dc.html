SPEC · A1·4 OVERLAY · full text in “A1 Headers — Spec.md”
Content fields Shared A1 list, plus logoLight (image, opt) — a second logo file for use on dark imagery. If absent, “Header colour on image: Light” renders the wordmark as text instead of the image logo rather than tinting the user’s PNG.
Data Ghost navigation as elsewhere. Depends on the section below it: if the first section has no image — or its image fails to load — the header renders as A1·1 Rail with the pack’s surface, and the editor says so in the sidebar. No transparent header over a flat pack colour, ever.
Responsive · empty · a11y 1440–768 transparent, nav folds to More past 4 items. ≤767 wordmark + toggle only, actions to the drawer. a11y: AA is checked against the scrimmed image, not the raw image — Subtle scrim is the minimum that passes at the drawn crop, and choosing None disables Light/Dark auto and warns. Drawer traps focus; Escape closes and returns focus to the toggle.
