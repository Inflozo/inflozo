WHAT THIS PANEL SETTLESReconciled. Image focus (Centre · Top · Bottom) arrives ⚑ in the Data group's Image Picker popover, for the uploaded image and the Ghost one alike — the category's "no focal point" refusal is withdrawn, and A30, A31 and A32 already carry the field. Background role is locked at Image and Vertical spacing resolves 0; Height keeps its own name because it is a media height. Eyebrow: Show · Hide added; the zero count string is now a catalog string. Seven controls of its own.There is no image-position control. The crop is centred and the text is bottom-left; a "focal point" control belongs to the image itself and Ghost has no focal-point data to read ⚑. That is a finding for the architect, not a control this design can invent.Scrim: Light is disabled against light images, with the measured ratio shown. The check runs on the image's bottom third, where the text actually sits ⚑ — not on its average, which is the value that lets a white sky through.When there is no image the panel says so in place and shows what will render instead. It does not silently switch the user to 1 Centred, and it does not offer a "pick another design" button ⚑.
