A15 reads nothing from Ghost but @site.title ⚑, so nothing here is Ghost-owned and no line shows the “Edit in Ghost” lock — the one Ghost value is the aria-label fallback, which is the site title and not a field. The action label is an authored field ⚑ — playLabel, default “Play”, ≤ 20 — and the duration suffix stays automatic: “Play · 12:40” is the label plus a generated span, never one typed string. Buttons accept an optional icon before or after the label from the P0·2 Icon Picker with its size / colour-role popover, off by default ⚑; the play control is not an icon slot ⚑ — it is A15’s own component and its glyph is not swappable. No fixed English visitor-facing string ships ⚑: transcriptLabel (default “Transcript”) is an authored field, and the notice sentence and its load action, the theatre’s close and counter, “Now playing”, the running-total prefix, the dead-URL line and the “Film {n}” fallback are theme translation-catalog strings.

Upload only ⚑ — an embed is never asked to autoplay; the facade exists to prevent the request. Ambient loop is muted, looped and playsinline ⚑ — muted is what makes autoplay browser-legal, which is why the value cannot be unmuted. The poster stands in under reduced motion and with no JavaScript ⚑.
ARCHITECT: REGISTRY ADDITION (ambient loop)Gating an autoplaying muted loop on prefers-reduced-motion is behaviour no registry module covers ⚑. The no-JS and no-module state is designed anyway — the poster with the native controls, which is Click to play — and no module name is coined.
