Panel and Panel padding → every .kg-card except .kg-header-card, which already carries a surface, and the HTML card, which has no element to carry one ⚑.Image in the panel → .kg-image-card .kg-image; at To the panel edge the padding is removed on the figure rather than added to the image.The panel is drawn on the card element Ghost already emits — A33 adds no wrapper, so the panel and the figure are the same box and the figure/caption pair survives.Space around cards → the adjacent-sibling margin on .kg-card, inside the theme’s own wrapper around the post body. This is the invented reading ⚑ — Ghost has no credit field — and it now carries a version risk: Ghost 6 strips em and strong from a feature-image caption while Ghost 5 keeps them (tested 2026-08-31). Whether the same stripping reaches a card’s figcaption is untested; the owner commissioned that test on 1 September 2026 and it stays open until it is run. One cost of the rule is accepted rather than solved (owner, 1 September 2026): a caption ending in italics for any other reason — a film title, a ship’s name — reads as a credit, and the Credit line control’s help text now says so in the editor’s own words.
THE WIDTH CLASSES · WHAT THE CARD WIDTHS ROW DEPENDS ON
.kg-width-wide and .kg-width-full sit on the card’s own element beside its card class — figure.kg-card.kg-image-card.kg-width-wide. These two are the whole of the width contract.Regular has no class on an image, gallery or embed figure — Ghost’s documentation says a normal-width card carries no extra class, so the regular rung is the card class’s own default and never a .kg-width-regular selector. The signup card is the exception: Ghost documents kg-width-regular on it. Do not write one rule for both.Two cards arrive with a width class already set ⚑: Ghost’s own markup ships .kg-header-card with kg-width-full, and its gallery example ships .kg-gallery-card with kg-width-wide. The signup card also provides .kg-content-wide at full width and .kg-layout-split when it carries an image.In this treatment: the panel takes the authored width and the media gives up 48 — panel 720 / media 672, 1,040 / 992, 1,296 / 1,248.
WHERE WE ARE NOT CERTAIN · SAID RATHER THAN GUESSED ⚑
Verified against Ghost’s theme documentation: .kg-card, .kg-image-card/.kg-image, .kg-gallery-card/.kg-gallery-container/.kg-gallery-row/.kg-gallery-image, .kg-bookmark-card and its eight parts, .kg-embed-card, .kg-callout-card/.kg-callout-emoji/.kg-callout-text, .kg-toggle-card/.kg-toggle-heading/.kg-toggle-heading-text/.kg-toggle-card-icon/.kg-toggle-content, .kg-button-card/.kg-btn, .kg-file-card and its parts, .kg-audio-card, .kg-video-card, .kg-header-card, .kg-signup-card, .kg-product-card/.kg-product-card-container, .kg-width-wide, .kg-width-full.Not verified, and flagged rather than guessed: the call-to-action card’s class (drawn here as .kg-cta-card) and the email-content card’s, neither of which appears in Ghost’s documented class list; the eight callout colour variants beyond .kg-callout-card-accent, whose pattern is .kg-callout-card-; the product card’s inner classes below .kg-product-card-container; and whether Ghost 6’s header card keeps the same class set. A wrong selector styles nothing silently, so each of these is written as unverified in the specification and none is used to carry a rule on its own.No class at all: the divider is a bare hr; markdown and HTML emit no wrapper; the public-preview cut leaves an HTML comment. The toggle exposes its state as [data-kg-toggle-state="close"|"open"] — a stylesheet can read the state, but only Ghost’s script ever changes it, so with JavaScript off the card stays closed.

A33 ships a stylesheet and nothing else, so the selector is the deliverable: inside a post’s body we own the stylesheet and not the markup, the ARIA attributes or the text. Nothing here assumes markup A33 would have to emit ⚑. One build fact belongs beside these: Ghost injects its own cards.min.css through ghost_head unless the theme’s package.json excludes a card in card_assets, so a treatment’s rules only take effect for cards on that exclusion list. Settled by the owner, 1 September 2026: A33 replaces Ghost's card CSS for all twelve excludable cards — nft ignored, since this category draws no NFT card — and the theme always re-includes Ghost's own cards.min.js, so A33 owns the look and Ghost keeps the behaviour. One condition, tested first and with its fallback already written ⚑: an exclusion takes a card's assets rather than its stylesheet alone, so if the served bundle turns out to be filtered by the config, the seven static cards are excluded and toggle, gallery, audio, video and signup stay on Ghost's assets, styled by a deeper selector — excluding those five would leave a card that renders and does nothing.

WHAT DOES NOT CHANGE · THE FOUR STATES EVERY A33 DESIGN OWES
In the editor every card draws at its resting state ⚑ — the toggle closed, no hover, no ring. The treatment is CSS, so the edit-time picture and the published picture are the same. With JavaScript off fourteen of the twenty cards are identical ⚑. Six depend on scripts that are Ghost’s or the provider’s, not A33’s ⚑: the toggle’s open and close, the gallery’s row ratios, the audio and video players, the signup card’s post, and the embed’s provider markup. The registry has no module for any of them — a finding, not a design, and A33 declares core rather than inventing one. The treatment never restyles what is inside an iframe ⚑. The embed card’s frame, radius and caption are A33’s; the provider’s markup is the provider’s. No control in A33 styles one card of one post ⚑ — a value is written once, site-wide, and every card of that type reads it.

The panel is what hovers, and it hovers by changing its surface — not by lifting. A panel that rose 2 px on hover would announce that every card is clickable ⚑ and only the bookmark is. The button card’s hover and every focus ring are 1 Plain’s, unchanged.

THE PLANE GROWS DOWNWARD · NO CLAMP, NO ELLIPSIS, NO SCROLL INSIDE A CARD ⚑

The panel holds its shape and its padding whatever is missing ⚑, which is this treatment’s advantage in the ugly test and its cost everywhere else: an empty optional field leaves a slightly shorter panel, never a hole. ACCESSIBILITY · THE MARKUP IS GHOST’S AND THE TREATMENT MUST NOT BREAK IT
THE MARKUP A33 STYLES · GHOST’S, ANNOTATED
IMAGE, GALLERY, EMBED<figure> + <figcaption> — the caption is inside the figure, so it is read with the image, not after it
BOOKMARKone <a> around the whole card · one focus stop · the thumbnail is aria-hidden and the title is the accessible name
CALLOUTa <div> with no role · the emoji carries aria-hidden ⚑ so it is not announced as “pushpin”
TOGGLEa plain <div> holding an <h4> and a <button> — not native disclosure markup ⚑. The heading is a real h4 and a stylesheet cannot change its level; the button is the only target and the only focus stop, and no theme can add the aria-expanded it lacks. Recorded as a Ghost limitation
BUTTONan <a> styled as a button · 48 px tall, 44 px minimum target at every width
PRODUCTGhost renders the rating as stars with no text equivalent ⚑ and a theme cannot add the words · recorded as a Ghost limitation, not something this category fixes
FILEthe link names the file and its size: “Download catalogue-2026-08.csv, 1.4 MB” ⚑
HEADERthe heading is an h2 ⚑ — Ghost emits h2/h3 and A33 never promotes one to h1; the post title is the page’s only h1
THIS DESIGN’S OWN ACCESSIBILITY NOTES
The panel is a <div> with no role and no label ⚑. It is a visual boundary; announcing “group” ten times in an article is worse than announcing nothing.The image card’s panel sits inside the <figure> ⚑, not around it, so the caption stays the figure’s caption and the reading order is image then caption.Contrast on the surface, not the ground: body 16.5 px at text on surface is 13.4:1, captions 5.7:1, and the accent button on surface is 3.9:1 for its fill with white label at 4.6:1 — all AA at these sizes.Focus rings are drawn outside the panel’s radius at a 4 px offset, so a focused card is never clipped by its own corner.

Ten panels do not add ten landmarks ⚑. The only structural change from 1 Plain is where the <figure> sits relative to the panel, and it sits outside — the panel is inside the figure.

WHAT GHOST OWNS · FIVE READ-ONLY ROWS · IDENTICAL IN ALL SIX · NOT COUNTED
Which cards appear
Whatever the author inserted🔒
Read-only. The author writes the post ⚑ — a treatment styles every card Ghost renders and cannot add, remove or reorder one. A33 has no item list.
Card widths
The author’s, per card🔒
Read-only. Regular, wide and full are authored in Ghost, one card at a time ⚑ — the treatment decides what each of the three resolves to, which is the whole of designs 4 and 5. The classes this row depends on are .kg-width-wide and .kg-width-full; regular carries no width class on an image, gallery or embed figure.
Bookmark metadata
Scraped by Ghost🔒
Read-only. Title, description, icon, author, publisher and thumbnail are all scraped from the URL ⚑ — C.1’s matrix. A treatment chooses which rows show, never what they say.
Gallery rows
Ghost’s own script🔒
Read-only. Ghost’s card script computes each row’s ratios ⚑ and no registry module covers it. With JavaScript off the images render at equal widths — a finding for the architect, not a degradation A33 can quote.
Corners
From the pack’s radius token🔒
Read-only in every treatment ⚑. C.1’s matrix lists corners as a per-card setting; A33 answers that the pack’s radius token is that value and offers no other — a card that mixed radii would fail §3·1 in eleven of twelve packs.

WHAT THIS PANEL SETTLESThe panel takes the authored width; the media gives up 48. The alternative — panel wider than the measure — was drawn and cut: it puts every card out of line with the paragraphs, which is a defect no user asked for and every user sees.Panel: Fill only exists for the packs, not for taste ⚑. 7 · Data. Everything comes from {​{content}​} as Ghost renders it — A33 adds no markup of its own ⚑. Zero cards → the treatment renders nothing at all: no wrapper, no padding, no trace, because there is nothing to select for. One card → it takes its own space and the article closes around it. Many → the rhythm is the space value, repeated; two cards of the same type in a row keep one space between them, not two ⚑. The same treatment renders on pages, and above a paywall cut inside A32’s preview.8 · Empty state. The panel keeps its shape and padding whatever is absent ⚑ — a missing field shortens the panel and never leaves a hole. No caption → no <figcaption>, the panel’s bottom padding closes the gap. No thumbnail → a panel of text at full width. No product image → panel of text plus rating. No cards → nothing renders, and in particular no empty panel ⚑. The header card gets no panel at any value — it carries its own surface.9 · Behaviour module. Modules: accordion for the toggle card, core for everything else — the same two in all six treatments, because a treatment is a stylesheet ⚑. Edit-safe: yes; the resting state is the only state and nothing animates, posts or pins while the post is edited. No-JS, quoted: accordion — the registry’s quoted degradation does not hold here ⚑ — Ghost’s toggle is a container with a heading and a button, not native disclosure markup, so with JavaScript off it cannot open. A33 declares accordion because it is the nearest module and records the mismatch as a finding. core — “Never runs; the .js-enabled class is never set, so all JS-conditional CSS stays in its no-JS branch.” The one gap is Ghost’s own gallery row script ⚑ — it computes each row’s ratios, the registry has no module for it, and with JS off the images render at equal widths. That is a finding for the architect, not a degradation A33 may quote.10 · Accessibility. As 1 Plain, with two changes: the panel is a div with no role and no label ⚑, and the panel sits inside the <figure> so the figure/caption pair is preserved and reading order stays image → caption. Focus rings draw outside the panel radius at a 4 px offset. Body on surface 13.4:1, captions 5.7:1.— · Repeating items. One authored array in the whole category: gallery.images[] ⚑. Its Add, Remove and Reorder are Koenig’s, on the canvas, not in this sidebar — the images belong to the post. Minimum 1, maximum 9 (Ghost’s limit); at 1 it renders as a single image at the card’s width, at 9 as three rows of three, and at 0 the card cannot exist — Ghost deletes an empty gallery card. No control in A33 styles one image, one card or one post ⚑: a value is written once, site-wide. Inside a card the author edits content only — text, image, link — never its layout.Flagged ⚑ — the panel taking the authored width while the media gives up 48; no panel around the header card; padding 16 at ≤ 767 overriding the control; the shadow kept at 390 and dropped in dark; the panel inside the figure; Fill only existing for the packs rather than for taste; the cut shadow-depth control.
