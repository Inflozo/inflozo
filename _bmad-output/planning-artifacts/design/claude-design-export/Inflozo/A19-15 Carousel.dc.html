Carousel

Three or five featured posts as full-width spotlights, one at a time, with dots under the slide and arrows beside the head. Fourteen designs in A19 declare no module; this one declares carousel, and it is the only piece of JavaScript the category can run.

It never autoplays and there is no control that would let it. ⚑ A spotlight that changes on its own takes the reader's place in the page away from them, and the registry's carousel module degrades to a native scroll-snap strip that is fully usable with JavaScript off — which is the reason this arrangement is shippable at all.

WHAT THIS PANEL SETTLES · AND THE THREE CONTROLS THAT ARE NOT HERE No Autoplay. ⚑ A moving spotlight competes with the reader, fails WCAG 2.2.2 unless it ships a pause control, and the pause control is a seventh element in a section that already has dots and arrows. The module supports paging on demand and this design offers only that. A user who wants motion has asked for a different section. No Loop and no Interval. The track stops at both ends with the arrow at that end disabled, which is what tells a reader they have seen all five. Looping a set of five with no page numbers is how a reader loses their place, and A19 has no page-number affordance to add. Every control writes one value onto the section and every slide reads it. Title size Large makes five 40 px titles, not one; Ratio 1:1 crops five pictures square. There is no per-slide anything, no Add, no Remove, and no reordering — Order is the only sequence control and the first post in it is always the slide shown at rest.

The numbering ruleThis is still design 15. A19 runs 1 to 15: nothing was renumbered, no number was reused, and no gap was created or closed.
Ghost's templates cannot count, add, or rememberThe dot label's two numbers are named. “Show post 3 of 5” takes its position from the loop's own counter and its total from a value the editor writes onto the track, because inside a loop a template cannot see how many items there are. No design ever turns into another designAt one post the dots and the arrows are hidden and the design draws itself — the rule's own example — and the module is not declared for that render. Navigation Arrows resolving to Dots below 1080 is a control value, not a design. Autoplay, Interval and Loop stay refused, owner-ratified.
The Remove button never greys outA19's only repeating list is the Hand-picked post picker and remove is never disabled on it. There is no minimum to defend: removing the last pick empties the list, When nothing matches applies, and the panel says so at the click. No Add creates a post and no Remove deletes one.
Member buttons are conditional · the no-JavaScript noticeNo subject, and it is worth stating why. Every action in this design is a link to a post — no sign-up, no subscribe, no paid tier, no form — so nothing renders conditionally on self-signup or a payment provider, and there is no form for a notice to replace. JavaScript off: the track is a native scroll-snap strip, fully usable, with only the dots and the arrow buttons hidden.
