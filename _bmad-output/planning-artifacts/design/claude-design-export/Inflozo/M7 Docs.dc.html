Connect your Ghost site

Updated Aug 2026 · 4 min read · works with Ghost 6.x

Inflozo talks to your site through a Ghost custom integration — the official, supported way for tools to work with Ghost. You'll create one integration and paste three values. Takes about a minute.

You need Admin access to the Ghost site. On Ghost(Pro), the Starter plan can't accept theme uploads — see Hosting requirements.

1 · Create the integration

In Ghost Admin, open Settings → Integrations, click Add custom integration, and name it Inflozo. Ghost shows you three values on the next screen.

screenshot: Ghost Admin → Integrations → Inflozo
the three values, for examplecopy
API URL https://orbitweekly.com
Admin API key 65a3f0e1c9d2…:9c2b41d8e0f7…
Content key 8d41c0a97b36…
Your Admin key is a secret — it can publish to your site. Inflozo stores it encrypted and never shows it again after you save. If it ever leaks, regenerate it in Ghost and update it under Sites → ⋯ → Manage API keys.

2 · Paste the keys in Inflozo

Back in Inflozo, paste all three values and hit Connect. We check the connection immediately and pull in your accent color, title font and body font so the canvas starts out looking like you.
