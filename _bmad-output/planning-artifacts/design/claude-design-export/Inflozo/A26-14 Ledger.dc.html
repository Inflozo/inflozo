Ledger

The footer as a colophon: a right-aligned label column and one line of fact per row — filed under, written by, published, updated, share, read next — every row a hairline apart, nothing taller than a line except the last.

It is the design that carries the dates and the credits ⚑ — A24 refused an "Updated 14 March" line in its headers and named A26 as its owner, and this is the design that owns it: the Updated row is post.updated_at and nothing else, with no authored note beside it. A3·11’s colophon set the pattern for a site; this is the same instrument for a post.

Bylines carry no number“Rosa Menendez and three others” is now “Rosa Menendez and others”. A template cannot subtract the drawn names from the author count, so the number could only ever have been hard-coded or wrong. The row, the avatars and the type are unchanged.
Avatars with no photographThe avatar fallback draws one letter — “Rosa Menendez” shows R. Every person here comes from Ghost, which cannot produce two initials from a display name, so two initials were never available. The circle, its sizes and its colours are unchanged.
Captions that carry a linkThe Photography row takes Post Headers’ treatment: feature_image_caption is rendered as HTML so the credit link a photographer needs survives. The old rule — “a <dd> of plain text, never a link” — is withdrawn: it was throwing away the one thing the field usually carries. The row itself is still never a link, the caption is still Ghost’s and still not inline-editable (“Edit in Ghost”), a link inside it takes the design’s own link colour and fills a 44 px target inside its row, and a post with no caption still draws no row.
