Single

One number as the whole section, at 128 px. The most-received design in the library so far — nine of A10's fifteen hand off to it when only one stat is authored — and the one place where the value is allowed to be the largest thing on the page by a wide margin rather than a narrow one.

It exists because a row of one is not a row. A single stat in 1 Row's 416 cell is a number in the left third of a section with two thirds of nothing beside it; the same number here is a statement. With two or more stats authored it draws the first and says so, which is the one place in A10 where a design leaves content out on purpose.

ACCESSIBILITY · ONE NUMBER, AND WHY IT IS STILL A LIST A <ul> of one <li>, holding one <p>. A list of one announces “list, one item”, which is one redundant phrase — and it is kept, because the alternative is a different structure at a different count, and a design that is a list at three stats and a paragraph at one is two designs to build and test. Nine other designs hand off to this one, so the structure a reader meets has to be the same structure. ⚑ Mine, and stated as a cost. The value is not an <h2> or an <h3> even at 128 px. This is the design where the temptation is strongest — it is visually the page's biggest thing — and a heading whose text is “41,800” is a heading rotor entry that tells a reader nothing about where they are. The <h2> is the title, as everywhere else in A10; at head None there is no <h2> and the section takes no accessible name. At Label Beside, the DOM order is value then label — the same as Under — so the two arrangements read identically and the control changes nothing but the visual position. The panel at Frame Panel is a plain <div> with no role and no label. Contrast: value 15.8:1 on ground light / 14.7:1 on the dark panel, label 5.6:1 / 5.8:1. Large text at 128 px passes AA at 3:1, so the value has 5× the contrast it needs — which is why it stays text and is never lightened for effect. One tab stop at most. At Count up Off no behaviour; at On the module animates a figure that was already rendered, which is why the refusal this design carried fell first here. Print and screen are the same drawing.

STATS · the item list · outside the design’s listStats is the P0·3 item list: Add stat arrives with content — value 100, label “What this number counts” — Remove is never disabled, drag to reorder, per-item content only. Per item: value ≤ 12 · prefix ≤ 3 · suffix ≤ 6 · label ≤ 60. note, prev and share held — note notably, which is why 12 Sourced keeps its own single stat. Value source: Authored · Member count · Paid member count. At Member count the value renders Ghost’s {​{total_members}} string verbatim — “1,200+” in, “1,200+” out, no maths and no formatter, which is the category’s own no-formatter rule — prefix and suffix are disabled and the label stays authored. {​{total_paid_members}} is offered only when the site has paid members enabled. One drawn at every authored count: the first row is the drawn one, and dragging a row to the top is the whole mechanism. Eight is the ceiling of stats[], raised from six in this pass: “Eight numbers is as many as a reader holds in one look. A ninth is a table, and a table is a different section.” 3 Grid is the only design that draws eight; everywhere else seven or eight authored names it.
EDITING · the P0 primitivesValue, prefix, suffix and label edit inline on canvas, selected where they are drawn rather than only in the repeater. The value raises no marks toolbar — it is plain text, so bold, italic and a link inside a figure are withheld rather than offered and refused. Eyebrow, title, sub, source and the link label take the P0·1 toolbar — bold · italic · underline · link, the popover carrying open-in-new-tab and rel nofollow · noreferrer · sponsored. A value bound to a member count is not inline-editable: clicking it says “Edit in Ghost”, because the figure is the site’s member list and not a word anyone typed here. sourceUrl and linkUrl open the Link Picker; the section link takes an optional P0·2 icon. This is the design a bound member count was written for — one figure, at 128 px, that a site never wants to retype.
BEHAVIOUR · from the fixed registrycount-up, from the fixed registry, and only at Count up On. Its own degradation is the argument: “The final value renders as static text — it is already in the HTML before JS ever runs.” JS off, reduced motion and assistive technology all get the figure rather than the animation, and the module does not re-run on the way back up the page. Edit-safe: it does not run while the section is edited, so every frame here is still a resting state. At Count up Off — the default — this design declares no module at all: Frame Panel is a fill, a hairline and 48 px of padding, Label Beside is a flex row on a shared baseline, and the forced move to Under at ≤ 767 is a media query.
DATA · Ghost’s two member helpers · outside the design’s listTwo figures in A10 can come from Ghost, and both are public theme helpers: {​{total_members}} and {​{total_paid_members}}, each rendering a pre-rounded string. They are reached from the item’s Value source and not from a “Populate from…” panel — there is no list to populate. Everything else is authored in this section. Refused on record: a post count from a tag (a number nobody wrote and nobody checks), any admin-API figure — opens, revenue, growth — a live figure from a third party, and the four ornaments: sparkline, dial, donut, pie. 9 Bars’ single proportional bar is as far as A10 goes.
