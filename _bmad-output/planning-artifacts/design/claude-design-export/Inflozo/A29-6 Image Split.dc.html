EDITING · THE P0 PRIMITIVESEvery authored string edits inline on canvas with the P0·1 toolbar — bold · italic · underline · link, its popover carrying Open in new tab and rel nofollow · noreferrer · sponsored: eyebrow, titleOverride, description, backLabel, emptyText. Ghost-owned content is never inline-editable ⚑ — the archive name, the post count, tag names, the author bio, location and website all answer "Edit in Ghost" or show P0·1's lock pill. Every URL field opens the Ghost-aware Link Picker. No fixed English visitor-facing string ships: the authored strings carry the old literals as defaults and the zero count is the archive.count_empty catalog string. There is no Preview control in this panel and there never was one to remove — states are P0·6's switcher, audiences are View as.Image focus is the pass's addition here ⚑ — Centre · Top · Bottom in the Image Picker's popover, on the uploaded image and the Ghost one. It does its most visible work at Square, where a landscape file is cropped hardest. Member Visibility lands nowhere — the only interactive element is the back link.

WHAT THIS PANEL SETTLESReconciled. Image focus (Centre · Top · Bottom) arrives ⚑ for the uploaded image and the Ghost one, in the Image Picker popover; the old "no focal point" refusal is withdrawn. Padding retired into Vertical spacing, Eyebrow: Show · Hide added, the zero count string moved to the catalog, Content and Data groups drawn. Six controls of its own.Image side changes the visual order and not the DOM order. The name is first in the markup at both values, so a screen reader and a keyboard get the same sequence either way ⚑. That is the same rule A5·7 set for alternating media and it is reused here rather than re-argued.Image shape is three named ratios, not a height. All three are 636 wide; the tallest is the square, which pushes the section to 636 px and is the reason Spacious padding is rarely wanted with it ⚑.No crop or focal-point control — same finding as 5: Ghost stores no focal point, so every crop in A29 is centred ⚑.
