From Ghost. No Add, no Remove, no drag handle and no per-post styling: at every value but Hand-picked this is Ghost's answer to a query, and Hand-picked picks posts rather than authoring them. Add and remove posts in Ghost — this panel chooses how many to show, in what order, and from where.
EDITING · THE P0 PRIMITIVESEvery visible authored text edits inline on canvas with the P0·1 toolbar — bold · italic · underline · link, its popover carrying Open in new tab and rel nofollow · noreferrer · sponsored: headingText, fallbackHeading, archiveLinkLabel, and nothing else. Post content is Ghost's and is never inline-editable ⚑ — clicking a post title, tag name, author name or excerpt says "Edit in Ghost". Every URL field opens the Ghost-aware Link Picker. A27 authors no image ⚑, so rule 10's Image focus has nothing to attach to: the crop is named by the Ratio ladder and the focal point belongs to the post, in Ghost. No button anywhere in A27 ⚑, so rule 11's optional icon has nowhere to sit — the archive link is text with an accent underline. No fixed English visitor-facing string ships: the three head strings are authored with the defaults shown, and the reading-time suffix is A24's site-level string. There is no Preview control and there never was one to remove.Member Visibility lands nowhere in A27 ⚑ — and that is a judgement, not an omission: nothing here is a CTA. A related post is navigation and the archive link is a route, so rule 9's control has no offer to gate and P0·4's member-aware action editor never opens. Recorded in the Reconciliation notes.
