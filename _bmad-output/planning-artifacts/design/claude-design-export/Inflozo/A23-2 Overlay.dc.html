2 · Overlay

A panel over the dimmed page, holding the field and five suggestion rows. This is the surface A1·9 Search-Forward opens, drawn once here so every header in the library opens the same thing.

It is the only design in A23 that is not part of the page it sits on: nothing above or below it moves, the page keeps its scroll position, and Escape returns the reader exactly where they were.

WHAT THIS DESIGN SETTLES FOR EVERY HEADER IN THE LIBRARY
A1·9 opens this. So do A1·2’s drawer field, A1·14’s ⌕ button and every other search affordance in A1 — one panel, drawn once ⚑. A header does not get its own results treatment.Five rows, then a way out. A1·9’s cap, kept: five rows and a “See all N” row into 1 Field and Results. The panel never scrolls internally ⚑ — if five is not enough the answer is the page, not a longer panel.It is a section for the editor’s sake, not the page’s. Nothing renders in the flow, so the section has no padding, no ground and no place in the page order ⚑ — which is why the universal trio is not drawn for it: there is no ground to role, no space to set and no edge to divide. ARCHITECT: editor-surface ruling ⚑ — the panel is chosen from a dedicated editor surface listed with the header that opens it, never placed in the page stack. 3 Command Palette is the same case and carries the same note.

The panel is sized by its content in every state ⚑ — one row is one row tall, five are five, and the no-match block is 132 px. A fixed-height panel with two rows in it looks broken, and that is the commonest overlay defect. Before a query the panel is not empty: recent searches, then featured, by the shared source group ⚑.

THE KEYBOARD MODEL · A1·9'S, MATCHED
⌘KOpens the panel from anywhere. The same shortcut A1·9’s field advertises; ⚑ the palette’s hint is 3 Command Palette’s, not this design’s.
↑ ↓Moves the active row. The panel scrolls the row into view; focus stays in the field — aria-activedescendant, never a real focus move ⚑.
↵Opens the active row. With no active row it submits the field, which is the GET form, which is the no-JS path.
escTwo steps, A1·9’s: first press closes the panel and keeps the query; a second press on an empty panel clears the field ⚑.
tabLeaves the field for “See all”, then the rows in document order. Focus is trapped in the panel while it is open — the one place in the library where it is ⚑.
WHAT THE MODEL SETTLES
Combobox semantics, and only here and in 3 Command Palette ⚑. role="combobox" on the field, aria-expanded, aria-controls and aria-activedescendant; the list is role="listbox" with role="option" rows. The eleven page designs are not comboboxes — their results are an ordinary
    in the document.The panel is a modal dialog with one exception. role="dialog" aria-modal="true", focus trapped, Escape closing — but the page behind is not made inert and keeps its scroll position, so a reader can read the page under the dim while the panel is open ⚑.A row’s accessible name is title, section, author, date — A1·9’s, matched word for word, so a reader who has used the header’s field hears the same row here.

THE SEARCH SOURCE · SEVEN ROWS · IDENTICAL WHEREVER RESULTS ARE DRAWN · NOT COUNTED
What it searches
Posts and pages▾
Posts · Posts and pages · Posts, pages and tags · Everything, including authors. Ghost decides what a theme can reach; this row says which of it this section asks for ⚑.
Search in
Titles and excerpts▾
Titles and excerpts · Full content. Full content is available here and is not in Ghost’s own bundle ⚑ — A23’s index is client-side over the Content API, which can return plaintext. It costs index size: roughly 4–8 kB a post, so a 400-post archive fetches a few megabytes before the first query. Titles and excerpts is the default, and this row is what the read-only line below reports.
Before a query
Recent searches, then featured▾
Recent searches, then featured · Featured posts · Latest posts · Nothing. Recent searches are the reader’s own and never leave their browser ⚑; a first visit falls through to the second value. “Most read” is gone ⚑ — Ghost gives a theme no view counts, so it was a promise the platform cannot keep.
Start searching after
3 characters▾
2 · 3 · 4 characters. A1·9’s three-character minimum and 200 ms debounce, carried ⚑.
How many results
20▾
10 · 20 · 50 · All matches. The cap is the section’s, not Ghost’s — the count line always names the true total ⚑.
Match highlight
MarkedPlain
A real <mark> at 16 % accent, 22 % in dark, in the title and the excerpt and never in the meta ⚑. At Plain it is absent from the DOM rather than untinted. Promoted here from 11 Thumb Rows, so every design that draws a result governs it in the same row ⚑.
What is indexed
Title, excerpt and slug🔒
Read-only, and it follows Search in ⚑. At Titles and excerpts it reads title, excerpt and slug; at Full content, title, excerpt, slug and body text. emptyText’s default follows the same value, which is why that sentence is a field and not a string.
EDITING · THE P0 PRIMITIVESThe panel’s own strings edit inline in the state that draws them, through the P0·6 switcher — No query · Results · No matches ⚑: placeholder, countLabel, seeAllLabel, recentLabel, suggestLabel, emptyHeading, emptyText, each with the P0·1 toolbar where marks are allowed. Row titles and meta are Ghost’s ⚑ — clicking one says “Edit in Ghost”. The keycap row is a translation-catalog string ⚑, not a field: “move”, “open”, “close”.
DATA · GHOST’S OWN, AND NEVER AN AUTHORED LISTRows are Ghost’s posts and pages: no Add, no Remove, no drag ⚑ (P0·3’s Ghost-sourced list). The reader’s recent queries are local to their browser and the publication can neither see nor seed them ⚑. No Member Visibility row ⚑ — the panel is a search surface, not a CTA.

WHAT THIS PANEL SETTLESNo backdrop control. The dim is the pack’s own text at 42 % and is not offered as a value — a blur is a pack decision and a lighter dim fails the panel’s edge on a pale ground ⚑.No “open on load” value. A search panel that opens itself is a takeover, and A2·12 owns takeovers. The panel opens from a trigger, always ⚑.No excerpt value — a suggestion row is title and meta. The excerpt is what makes the page’s row a result row ⚑, and the page is 1 Field and Results.Match highlight is the source group’s now ⚑, not a per-design row — the panel marks the query in its titles like every other design that draws a result.
