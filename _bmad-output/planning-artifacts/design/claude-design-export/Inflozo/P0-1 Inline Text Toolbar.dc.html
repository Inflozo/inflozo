P0·1 · Inline text toolbar

The floating toolbar that appears when text is selected in any inline-editable text prop, headlines included (FR-D4). One row, five actions: Bold · Italic · Underline · Link · Remove link. No font control, no size, no colour — those belong to the Style Pack and the section, never to a selection.

The Link action opens the Ghost-aware Link popover drawn below. A text prop bound to a Ghost Admin setting is plain-text-locked: the toolbar never appears on it.

FIVE ACTIONS, NOTHING ELSE ⚑ · REMOVE LINK IS DISABLED AT 35% WHEN THE SELECTION CARRIES NO LINK · ⌘B ⌘I ⌘U ⌘K WORK WITHOUT THE TOOLBAR

The toolbar is editor chrome, not canvas content — white surface, editor border, 10 px radius, md shadow, five 30 px targets. It centres over the selection, 8 px above; when the selection starts in the top 48 px of the canvas it flips below. B, I and U are letterform glyphs in the canvas serif so they read as text marks; Link and Remove link are stroke icons behind a hairline divider. Remove link renders always and disables when the selection has no link — a five-slot toolbar that never changes width is the whole point of a fixed vocabulary.

One popover, two states, and editing re-opens the same popover pre-filled — there is no separate "edit link" surface. The search state is the A1 dropdown panel grammar at 340: grouped rows, matched substrings bold, group labels in 10.5 px caps. Portal actions are chips, not rows, because they are four constants, not search results. The Rel toggles write real rel attributes and nothing else; they are mono-labelled because they are code values shown honestly, the one place the library shows a literal.

Orbit Weekly Site title — plain text, set in Ghost
THE SELECTION SHOWS, THE TOOLBAR DOES NOT · IN ITS PLACE, THE LOCK PILL NAMES THE BINDING · EDITING THE TEXT EDITS THE GHOST SETTING ⚑

Bound text is plain-text-locked by construction: site title, site description, member counts, author names — anything whose value lives in Ghost Admin or Ghost data. Selecting it shows the selection and a lock pill where the toolbar would sit, naming the binding. The pill is informational, not a control; ⌘B on locked text does nothing and nothing flashes.
