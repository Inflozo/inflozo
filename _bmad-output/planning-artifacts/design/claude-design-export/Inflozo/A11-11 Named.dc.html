Named

A caption under each logo. The only design in A11 that draws caption, and the answer to the half of §8.4 that asks what a caption is for: not the mark's name, which the artwork already says, but what that name did — “Reprinted the archive”, “Ran the correction”, “Books desk, since 2021”.

It carries A11's one equalisation: the caption block takes the height of the tallest caption in its row so the logos still share a centre line. That is A10·1's rule for the same problem, and this design is the only place in the category it applies.

ACCESSIBILITY · A CAPTION THAT IS NOT A FIGCAPTION The cell is an <li> holding an <img> and a <p> — not a <figure> with a <figcaption>. A figure is a self-contained unit referenced from elsewhere in the document; a logo in a wall is a list item. A11's floor refuses <figure> everywhere and this design is where the temptation is strongest, so the refusal is restated here rather than assumed. The announcement is the alt then the caption, as two separate strings — “Meridian Press. Reprinted the first year of the archive.” — with no aria-describedby joining them, because they are already adjacent in the reading order and a description relationship would announce the caption twice on some readers. Where a URL is authored the <a> wraps both the image and the paragraph, so the accessible name is the alt plus the caption and the target is the whole cell. A paragraph inside a link is legal and is what makes the caption clickable; the alternative — a link on the image and a caption outside it — puts two targets in one cell for one destination. The reserved space under a captionless logo is empty and announced as nothing — no visually hidden text, no &nbsp;, no empty <p> in the DOM. The space is the row's equalised height, which is CSS, not content. Contrast: caption 5.6:1 light / 6.0:1 dark, rising to 15.8:1 / 15.1:1 on a linked cell's hover and focus where it resolves to text; title 15.8:1 / 15.1:1; hover fill 1.2:1 / 1.4:1 decorative. A logo takes no ratio. At 400% the captions reflow and the equalisation follows them, so nothing overlaps and nothing is clipped. Reduced motion removes the 160 ms transition on the fill and the caption's colour and keeps both end states. Print draws the captions; they are the reason to choose this design.

EDITING · the P0 primitivesEyebrow, title, sub, note and the link label edit inline on canvas with the P0·1 toolbar — bold · italic · underline · link, the link popover carrying Open in new tab and rel nofollow · noreferrer · sponsored. linkUrl opens the Ghost-aware Link Picker, and the section link takes an optional P0·2 icon before or after its label, off by default. alt is edited in the item row rather than on canvas, being the one required string this category never draws. Nothing here is Ghost-owned, so nothing answers “Edit in Ghost” — every word is authored in this section and every mark is a site upload. Captions edit inline in the cell, one at a time; a caption inside a linked cell is edited in place rather than in the repeater alone, and it is still part of the link’s name.
