Inline

One sentence with the numbers set inside it at 34 px. The site writes the grammar and the section supplies the figures, which is the opposite arrangement to every other design in A10: there is no row, no cell, no divider and no baseline shared between values, because the values are words in a paragraph.

It is the one design that reads lede, and the one that does not draw label. The sentence around a figure does the label's work, so the labels are kept and left undrawn, and the panel says how many. With no lede authored the section draws 1 Row.

The paragraph's leading is set by the value, not by the body size: value plus 12 px, at every width and both sizes. Here that is 46 px on 20 px text, which is loose for prose and exactly enough that a 34 px figure never touches the line above it. At Large 44 the leading is 56. A paragraph set at a normal 1.65 would have the numbers colliding with the descenders overhead, and a value scaled down to fit ordinary leading is 24 px, which is a bold word rather than a figure. ⚑ Mine: the rule, both figures, and the refusal of the smaller value.
The value keeps the heading font, tabular figures, and its prefix and suffix at 0.5em — the same stat component as every other design, set in a line of text. It takes no accent, no underline, no weight change in the words around it and no baseline shift, and each value with its units is one unbreakable run.

The lede carries a chip per stat, in the repeater's order, and the site puts each one where the sentence needs it. The chip is inserted from the editor's toolbar and shows the stat's number and its current value; editing the stat changes what the chip draws. A chip cannot be typed by hand and a value cannot be typed into the sentence — a figure typed twice is a figure that gets updated once. ⚑ Mine: the whole mechanism. A stat with no chip in the lede is not drawn, and the panel names it: “Stat 3 is not placed in the sentence.” Nothing is appended to the end of the paragraph and no fallback row is drawn under it. A chip whose stat has been deleted is removed from the sentence with the stat, which leaves the site's own words on either side of the gap to fix. ⚑ Mine. Labels are kept and not drawn, and the panel says how many. The words around a figure are doing the label's work, and drawing both would say “41,800 readers” twice. Switching to 1 Row draws them again, which is what makes this safe: the content is not lost, it is unread by this design. The lede is the section's only prose and it takes text, not text-muted — it is reading matter, and A9's answer set the precedent. The sub field is kept and not drawn, because a muted 17 px line above a 20 px paragraph is two ledes.

ACCESSIBILITY · ANNOTATED · ONE PARAGRAPH, READ AS ONE SENTENCE The section is an <h2> and one <p>, and the values are <span>s inside it. There is no <ul> and no list item anywhere in this design — the only one in A10 without them — because a list of three inside a sentence would be announced as a list and read as an interruption. A screen reader gets the sentence, once, in the site's own words. ⚑ Mine, and the reason this design is structurally different rather than visually different. The value is not a heading, not <strong>, not <b> and not <data>. A <strong> announces emphasis a site did not write, and the figure is already the loudest thing in the paragraph visually. The undrawn label is not read out either — no visually hidden text, because text for one reader and not another is two versions of a section. A9·11's rule. The 46 px leading is a readability decision as well as a typographic one. A reader magnifying to 200% gets a paragraph whose lines stay separable, and at 400% the sentence reflows without the figures overlapping, because the line box is set from the value's own size rather than a fixed pixel height. Nothing here is clipped or scrolled at any zoom. Contrast: lede and value 15.8:1 light / 15.1:1 dark, source 5.6:1 / 6.0:1, link underline 3.3:1 / 6.3:1. No motion: the numbers do not count up and the sentence does not assemble itself. One tab stop, on the link, plus one per link inside the lede. Print draws the paragraph as it stands.

ICONS · not offered hereThe one design in A10 that does not take the icon offer. EDITING · the P0 primitivesValue, prefix, suffix and label edit inline on canvas, selected where they are drawn rather than only in the repeater. The value raises no marks toolbar — it is plain text, so bold, italic and a link inside a figure are withheld rather than offered and refused. Eyebrow, title, sub, source and the link label take the P0·1 toolbar — bold · italic · underline · link, the popover carrying open-in-new-tab and rel nofollow · noreferrer · sponsored. A value bound to a member count is not inline-editable: clicking it says “Edit in Ghost”, because the figure is the site’s member list and not a word anyone typed here. The chip insert reuses the P0·1 toolbar’s own frame — one more button in the same popover, at the same height, with the same chrome — rather than a second popover style: selecting inside the lede raises bold · italic · link and Insert figure, which drops the next undrawn stat’s chip at the caret. sourceUrl and linkUrl open the Link Picker; the section link takes an optional P0·2 icon.
