6 · Rail

The label, the count and the house rules stand in a 240 px rail in the page margin, on A25's 240 · 48 · 1,008 division; the block takes the 1,008. The head is not above the conversation, it is beside it, and it stays legible from the first comment to the last.

Below 1,200 there is no margin to stand in. The rail leaves and its content goes above the block — the same width-driven departure A25·1 and A25·7 made, and the reason this design states 1,200 rather than a breakpoint ⚑.

No control anywhere in A28 claims to style inside Ghost’s component ⚑ — mode and saturation pass through, and everything else in this panel is the chrome around the block. EDITING · THE P0 PRIMITIVESEvery visible authored string edits inline on canvas with the P0·1 toolbar — bold · italic · underline · link, its popover carrying Open in new tab and rel nofollow · noreferrer · sponsored: headingText (the rail’s label), rulesText, each rule in rules[], closedNotice. Ghost-owned content is never inline-editable ⚑ — the comment count, and every name, avatar and word inside the block, say “Edit in Ghost” or show P0·1’s lock pill. No fixed English visitor-facing string ships: the count’s three words are authored fields with the old literals as their defaults, and aria-label="Comments" plus the <noscript> line are translation-catalog strings. There is no Preview control and there never was one to remove.Member Visibility lands nowhere in this design ⚑ — nothing the theme draws here is a CTA. P0·4 and P0·2 never open. Rule 10’s Image focus has nothing to attach to.

WHAT THIS PANEL SETTLESReconciled. Padding retired into Vertical spacing, Divider into Top divider. rules[] is settled at one to four with P0·3’s item controls named. The count’s three words become fields ⚑ — the row that matters most here, where the count is 22 px and “No comments yet” is the biggest thing in the section on a quiet post. Match the page resolves to auto on a dual-mode site; the block group is recut as the Data group. Four controls of its own.No Heading control, which is the one place A28's shared control set is broken and it is broken deliberately: the rail is the head, so a control offering Label · Heading · Count only · None would be offering to draw a second one. A27·7 Rail made the same call for the same reason ⚑.Sticky rail is off by default. A rail that follows the reader down a long thread is useful; a rail that follows them down a 40-comment thread is a rules list that will not leave. The value is there and the default is the quiet one ⚑.The rules item editor is the same one 2 Split Head uses, verbatim — add, drag, remove, minimum two, maximum four, new item reads "Be kind".
