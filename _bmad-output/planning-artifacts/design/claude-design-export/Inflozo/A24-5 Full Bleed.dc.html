WHAT THIS PANEL SETTLES A standing precondition is a new kind of panel element and A34's standing warning is its precedent. ⚑ It sits above the controls, it is permanent rather than conditional, and it names another section and offers to open it. The editor cannot enforce a relationship between two sections — nothing stops a user setting a solid header — so the section states the dependency where the user is already looking. A finding for the architect: the section picker should carry this too, before the design is chosen rather than after. Two block fields are changed and they are changed differently, which is the point of having five verbs. Feature image is locked — the value stays visible and cannot be moved, because the design without it is not a variant, it is another design. Standfirst is inert — the value can still be set, it simply is not drawn here, and it returns the moment the design is switched or the header hands off. Title size drops Small and adds Display 76, and it is the only design in A24 with a value above 64 outside 10 Big Type. ⚑ That is allowed because the type is not on the page — it is on a 620 px photograph, and scale on a picture is a relationship rather than a shout. 76 on 1,296 px of image is the same optical weight as 50 on the page. Cut: a "darken the whole image" toggle (Scrim already does it, honestly, and only where it is needed); a focal-point picker (Ghost's crop, not the section's); and a scroll parallax — no module covers it, the nearest is reveal, and a title that moves while a reader is trying to read it is not a title.
