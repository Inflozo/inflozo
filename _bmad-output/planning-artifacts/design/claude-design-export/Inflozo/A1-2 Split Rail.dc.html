A centred wordmark cannot survive a 58 px bar without crowding the nav, so the sticky state re-forms as Rail: logo left, nav single-file after it.

This is the one structural change any header in the library is allowed to make on scroll, and it is why Rail is design 1 — every other design falls back to it. 160 ms ease-out at 80 px.

Children expand in place rather than sliding the drawer to a second panel — no back button to find, and the parent stays visible so you know where you are. The caret is the one accent use in the drawer, the list is indented against a hairline, and children drop to body size so the heading font stays a level marker. The list scrolls; “Subscribe” pins to the foot on its own hairline, so the primary action never scrolls away. Expanding one parent collapses any other.

SPEC · A1·2 SPLIT RAIL · full text in “A1 Headers — Spec.md”
Content fields Same A1 field list as design 1. Uses: logo, siteTitle, navItems (6 shown at ≥1024, 3 at 768–1023; overflow folds to More — the split assigns 1–3 left, 4–6 right), navItem.children, ctaLabel/ctaUrl, searchEnabled. Does not use signInLabel; if the user filled it, it renders in the drawer, never lost.
Data Ghost navigation, split by index. Odd counts weight left (3/2), which is why “Split: Even” cannot be honoured at 5 items — it degrades to Weight left and the control shows that. 0 items → centred wordmark alone, bar keeps Comfortable height.
Responsive · empty · a11y 1440–1024 three-column. 1023–768 even narrowing, items 4+ to More. ≤767 hamburger left / wordmark centre / search right, CTA moves into the drawer and pins to its foot. Children expand in place in the drawer, one parent open at a time. a11y: DOM order is logo → nav → utilities regardless of visual split, so focus order never zig-zags; one nav landmark, not two.
