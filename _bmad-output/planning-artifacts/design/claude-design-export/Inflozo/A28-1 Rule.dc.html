No control anywhere in A28 claims to style inside Ghost’s component ⚑ — mode and saturation pass through, and everything else in this panel is the chrome around the block. Type, spacing, avatars, buttons, threading, the editor and every focus ring inside the dashed outline are Ghost’s. A <noscript> line now sits under the head ⚑ — “Comments need JavaScript.”, a theme translation-catalog string (comments.noscript), not an authored field — so the chrome stops promising a thread that never loads. Drawn once, on the category proof frame.
EDITING · THE P0 PRIMITIVESEvery visible authored string edits inline on canvas with the P0·1 toolbar — bold · italic · underline · link, its popover carrying Open in new tab and rel nofollow · noreferrer · sponsored: headingText, rulesText, closedNotice. Ghost-owned content is never inline-editable ⚑ — the comment count, and every name, avatar and word inside the block, say “Edit in Ghost” or show P0·1’s lock pill. No fixed English visitor-facing string ships: the count’s three words are authored fields with the old literals as their defaults, and aria-label="Comments" plus the <noscript> line are translation-catalog strings. There is no Preview control and there never was one to remove.Member Visibility lands nowhere in this design ⚑ — a judgement, not an omission: nothing the theme draws here is a CTA. The one call to action on the page is inside Ghost’s block, and Ghost gates it. P0·4’s member-aware editor never opens; P0·2’s Icon Picker never opens either, because this design draws no button. Rule 10’s Image focus has nothing to attach to — A28 authors no image at all.

THE WRITTEN SPEC · ALL TEN FIELDS
1 · Descriptor. One hairline, a labelled count and a line of house rules above Ghost's block, on the article measure. The category default.2 · Structural descriptor. stack · none · page · none · none · one hairline above a labelled count
Containment none — the section draws no box and no plane. Count none — the section itself repeats nothing; the comments repeat inside Ghost's block and are not the section's items ⚑.3 · Archetype. stack. No departures — a stack is already what the ladder collapses everything else into.4 · Responsive rule. 1440 measure 720 centred on a 72 margin, hairline the full measure, label 13 uppercase, count 15 at the right, rules 15 clamped at 620, 36 to the block, padding 96. 834 measure 754, padding 80, everything else held. ≤ 767 measure 350, count under the label ⚑, rules 15 full width, 28 to the block, padding 64.5 · Content fields. headingText text opt 40 ch, default "Discussion" ⚑ · rulesText text opt 140 ch, one line ⚑ · closedNotice text opt 80 ch. Read from Ghost: {​{comment_count}​} and {​{#if comments}​}. No post field, no image, no author — A28 draws no pictures anywhere.
6 · Controls, in sidebar order. Heading (Label · Heading · Count only · None) · Count (Beside · Under · Off) · House rules (On · Off) · Width (Measure · Content). Four. Then the universal trio — Background role · Vertical spacing · Top divider — and the Data group.7 · Data. {​{comment_count singular=countSingular plural=countPlural empty=countEmpty}​} for the count ⚑ and {​{comments title="" count=false}​} for the block — the block's own title and count are always off, in all ten designs ⚑, because the section draws them. 0 → "No comments yet" and the block renders its editor. 1 → "1 comment". Many → Ghost paginates inside the block; the section neither knows nor cares.8 · Empty state. No rulesText → the line and its 12 px go; head sits 36 above the block. {​{#if comments}​} false → the notice replaces the block at When commenting is off · Show the notice, or the whole section goes at Hide the section. The section never draws a placeholder comment, an outline or a reserved height ⚑.9 · Behaviour module. none. The block loads its own script, which is Ghost's and is not in the registry ⚑. No-JS: the frame is pixel-identical and the block does not render — Ghost's comments-ui is a script, so with JavaScript off the head, count, rules and hairline stand alone. That is a category-wide finding, not a design defect ⚑ (finding 3).10 · Accessibility. <section aria-labelledby> named by the head, which is an h2; aria-label="Comments" at Heading None ⚑. The count is inside the heading, not a separate landmark. The rules line is a <p>. Focus order enters the block after the rules line and the theme has no control of it inside ⚑ — Ghost owns every stop in there.Flagged ⚑ "Discussion" as the default head · empty="No comments yet" · always passing title="" count=false · the count moving under the label at 390 · Width doing nothing below 834 · A28 sitting below A26 and above A27 · the section drawing nothing extra when signed out · no-JS leaving the frame alone.
