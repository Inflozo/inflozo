The header inside the measure: a hairline box aligned to the content column, so the nav starts exactly where the first paragraph starts. No shadow, no lift, no capsule — where Floating Pill is an object hovering over the page, this is a ruled block sitting in it, which suits a site whose pages are documents rather than screens.

The last focusable item sits 22 px from the box’s own hairline, so a 2 px ring at 2 px offset has clear air. At Compact height that margin drops to 14 px, which is still clear — this is why the box has 22 px side padding rather than the 18 px a bare rail would use.

Dark mode is where a hairline box is most at risk: the pack’s dark border is only a step from its background, so the box can vanish. It holds because the border is the dark-mode border token rather than a dimmed version of the light one — the packs already tune this, and this design is the reason they must. A pack whose dark border falls below 1.5:1 against its background renders the box Filled instead, and the sidebar says so.

The drawer grows out of the box and keeps its inset and hairline, filling with surface because a transparent full-height panel would show the page through the navigation. ACCESSIBILITY · a container that carries no meaning
1The box is decoration. It is the <header>’s own border, not a nested region, so nothing extra is announced. Semantics are Rail’s throughout: one nav labelled Primary, wordmark as home link, buttons for dropdown triggers, skip link first.
2Focus rings need air inside a border. 22 px side padding guarantees a 2 px ring at 2 px offset never touches the box’s hairline; the ring is drawn inside, never clipped. This is the reason the padding is not 18.
3The hairline is not the only signal. In forced-colours mode the box takes a system border and the fill is dropped; nothing about the header’s structure depends on seeing the outline, since the items inside are ordinary links.
4Sticky must not eat an anchor target. When the box sticks it is 60 px plus a 14 px inset, so in-page anchors get 74 px of scroll padding — otherwise a heading linked from the table of contents lands underneath it.
5Dark-mode border check. A pack whose dark border falls under 1.5:1 against its background renders Filled instead of Hairline, so the header never becomes an invisible container — the check runs per pack, not per site.
