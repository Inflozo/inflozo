1 · Field and Results

A centred head, one field beneath it, and the results in a single column on the page ground. The category default and the arrangement the other fourteen depart from.

It is the design for a publication whose search is a page: the reader arrives at /search/, types, and the list under the field changes. Nothing is raised, banded or photographed.

WHAT THE SEVEN STATES SETTLE FOR THE WHOLE CATEGORY
The count line is the announcement. Where results replace in place without a navigation it is a visually-hidden aria-live="polite" region as well as visible text — “12 results for orbital” ⚑. Where the query was a page navigation there is no live region: A34’s rule, a page navigation announces itself.One row, two densities ⚑ — the suggestion row is title plus “section · author · date”, and the result row is that same row with an excerpt. A1·9’s accessible name, matched exactly.No matches is a content state, not an error. No red, no icon: the query in the heading, one line of why, and the section chips as the way out. The line names the index — and the index is whatever the source group’s Search in row says it is ⚑, so a reader who searched a word inside an article is told which of the two they asked for.The no-JS floor is the field and the archive link ⚑ — a Ghost template cannot read ?q= or search server-side, so a GET to /search/ lands on a page whose results the same client module renders. No JavaScript, no results, in any of the fifteen — every no-JS frame in the category draws that rather than a rendered list.

Seven states, one field. The field never moves between them: 52 px, the same 520 width, the same axis. Before a query the list slot carries the reader’s own recent searches, then the site’s featured posts — the shared source group chooses which, and “most read” is no longer offered ⚑ because Ghost gives a theme no view counts. Searching dims the previous list rather than emptying it ⚑, so the page does not jump between a full list and a blank one on every keystroke.

THE SEARCH SOURCE · SEVEN ROWS · IDENTICAL WHEREVER RESULTS ARE DRAWN · NOT COUNTED
What it searches
Posts and pages▾
Posts · Posts and pages · Posts, pages and tags · Everything, including authors. Ghost decides what a theme can reach; this row says which of it this section asks for ⚑.
Search in
Titles and excerpts▾
Titles and excerpts · Full content. Full content is available here and is not in Ghost’s own bundle ⚑ — A23’s index is client-side over the Content API, which can return plaintext. It costs index size: roughly 4–8 kB a post, so a 400-post archive fetches a few megabytes before the first query. Titles and excerpts is the default, and this row is what the read-only line below reports.
Before a query
Recent searches, then featured▾
Recent searches, then featured · Featured posts · Latest posts · Nothing. Recent searches are the reader’s own and never leave their browser ⚑; a first visit falls through to the second value. “Most read” is gone ⚑ — Ghost gives a theme no view counts, so it was a promise the platform cannot keep.
Start searching after
3 characters▾
2 · 3 · 4 characters. A1·9’s three-character minimum and 200 ms debounce, carried ⚑.
How many results
20▾
10 · 20 · 50 · All matches. The cap is the section’s, not Ghost’s — the count line always names the true total ⚑.
Match highlight
MarkedPlain
A real <mark> at 16 % accent, 22 % in dark, in the title and the excerpt and never in the meta ⚑. At Plain it is absent from the DOM rather than untinted. Promoted here from 11 Thumb Rows, so every design that draws a result governs it in the same row ⚑.
What is indexed
Title, excerpt and slug🔒
Read-only, and it follows Search in ⚑. At Titles and excerpts it reads title, excerpt and slug; at Full content, title, excerpt, slug and body text. emptyText’s default follows the same value, which is why that sentence is a field and not a string.
EDITING · THE P0 PRIMITIVESEvery visible authored text edits inline on canvas with the P0·1 toolbar — bold · italic · underline · link, the link popover carrying Open in new tab and rel nofollow · noreferrer · sponsored: the eyebrow, the heading, the blurb and the note. Post titles, excerpts, tag and author names are Ghost’s ⚑ — clicking one says “Edit in Ghost”. The strings that never show at rest — countLabel, emptyHeading, emptyText, emptyLinkLabel, recentLabel, suggestLabel — are edited in the state that draws them, through the P0·6 switcher: No query · Results · No matches ⚑. The archive link opens the Ghost-aware Link Picker.
DATA · GHOST’S OWN, AND NEVER AN AUTHORED LISTResults are Ghost’s posts and pages, so P0·3’s Ghost-sourced rules apply: no Add, no Remove, no drag ⚑ — “Add and remove them in Ghost; this design chooses how many to show.” Order is the query’s answer and is not selectable. No Member Visibility row ⚑ — nothing in A23 is a CTA: the field is a form and the archive link is navigation.

WHAT THIS PANEL SETTLESPadding is gone from this list ⚑ — it was the trio’s Vertical spacing under another name, and the same three values now sit outside the list with every other section in the library.Nothing here is per-result. Density, excerpt, meta and the count line write one value onto the section; the stylesheet reads it for every row. A row is content, not a design — selecting one on the canvas is selecting a post, and posts are edited in Ghost.The source group is where search itself is configured: what it searches, how deep ⚑, what stands in before a query, the character minimum, the cap, the match mark, and the read-only line that reports the index rather than asserting it.
