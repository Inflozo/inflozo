WHAT WAS REFUSED HERE
A date column was considered and refused ⚑. Nothing in the item carries a date — images[] is image, alt, caption, link — and inventing one would add a fourth field to every item in the category for the benefit of one design. The finding is recorded rather than the field added.A sortable header was refused ⚑ — sorting is a client-side behaviour, the registry has no sort module (shuffle is the nearest and it randomises), and a gallery whose order the author set should not reorder itself.The thumb can be switched off entirely ⚑, at which point this design is a list of captions with a lightbox behind it — which is a legitimate picture-credits section and the reason the value exists.

A row with no caption draws its number and its thumb at full row height ⚑ — the text cell is simply empty, never “Untitled”, never collapsed. That is A16·13’s rule for an empty note cell, carried verbatim. At one image the index is one row with two hairlines ⚑, which looks like what it is: a list of one.

EDITING · the P0 primitivesEyebrow, heading, blurb and credit edit inline on canvas with the P0·1 toolbar — bold · italic · underline · link, the link popover carrying Open in new tab and rel nofollow · noreferrer · sponsored. Every caption edits inline in its row, at 17 px in text — this is the caption-led design and the row is the editing surface. The caption now holds 200 characters ⚑, raised from 80 in this pass. Every URL field opens the Ghost-aware Link Picker — per-image link included. At Source: From posts the caption is the post’s title and Ghost-owned: the toolbar is replaced by the plain-text lock pill and clicking says “Edit in Ghost”. The number is never editable ⚑ — it is a rendering of position, so there is nothing to click and nothing to type. No fixed English visitor-facing string ships ⚑ — the lightbox’s close, previous and next labels, its counter, the scrollable-row group name and 15 Boxed’s “photograph / photographs” are theme translation-catalog strings; every visible line is an authored field.
BEHAVIOUR · from the fixed registrylightbox, edit-safe: no ⚑ — it does not open in the editor, so what the editor draws is the resting set. No-JS, quoted: “Each thumbnail is an <a href> to the full-size image; clicking opens it as a normal page.” A14 satisfies that by construction — the frame is that link before any script runs. At Lightbox: Off no module is declared ⚑ and the section is pixel-identical with JavaScript off. With JavaScript off this is the strongest design in A14 ⚑ — a numbered list of captions, each a link to a full-size photograph, which is a perfectly good archive index. There is still no sort module and none is coined ⚑. Nothing else in the registry is claimed — no reveal, no shuffle, no load-more, and no module name is coined ⚑.

THE WRITTEN SPEC · ALL TEN FIELDS
1 · Descriptor. The set as a ruled list: a mono number, the caption at 17 px in the text role, and a 128 × 96 thumb at the right of each row, hairlines between.2 · Structural descriptor. table · none · page · many · right · a ruled row per photograph
The only table in A14 and the only media right. It is the one design where the photograph is subordinate to its caption, and the tuple says so in two slots.3 · Archetype. table. One departure — the row never becomes a stacked card at any width ⚑.4 · Responsive rule. 1440 number 40 · caption flexible · thumb 128 × 96 · gap 24 · row 80 px · hairline between rows. 834 thumb 104 × 78, gap 20. ≤ 767 number 32, thumb 72 × 54, gap 12, caption 15 px, row 64 px ⚑.5 · Content fields. The category’s five. The caption is required in practice here ⚑ — a row without one is legible but empty — and the editor says so rather than enforcing it.
6 · Controls. Thumb Small 88 · Medium 128 · Off — Row height Compact · Comfortable — Rules Between rows · Ends only — Numbering On · Off — Lightbox On · Off. No Captions control ⚑ — the caption is the row. Five plus the universal trio, the images item list and the Data group; Padding retired into Vertical spacing, Row height keeping its own name ⚑. The caption now holds 200 characters ⚑ — the caption-led design was the one most starved by 80.7 · Data. Nothing is read from Ghost’s content API ⚑ — the list is authored in the section. Ghost supplies the img_url derivatives (w=600 · 1000 · 1600 · 2400) for the srcset, and the lightbox requests the original file ⚑. 0 images → the section does not render on the published page ⚑; in the editor it draws a drop zone carrying “Drag photographs here, or choose from your library” ⚑. 1 → one row between two hairlines ⚑. many → the list runs as long as the list is, to the 48 ceiling; there is no pagination and no load-more ⚑ — the module exists but a 48-row list does not need it, and the panel says so.8 · Empty state. A row with no caption keeps its full height with an empty text cell ⚑ — A16·13’s rule, carried verbatim. At Thumb: Off a row with no caption is a number alone, which the editor flags on the item rather than in the section.9 · Behaviour module. lightbox, edit-safe: no ⚑ — it does not open while the section is being edited, so the resting grid is the frame the editor draws and the overlay is specified rather than triggered. No-JS, quoted: “Each thumbnail is an <a href> to the full-size image; clicking opens it as a normal page.” A14 reads that as: every frame is already an <a href> to the original file, so with no script the gallery is a set of links to full-size images and nothing is lost but the overlay. With JavaScript off this is the strongest design in A14 ⚑ — a numbered list of captions, each a link to a full-size photograph, which is a perfectly good archive index.10 · Accessibility. Heading h2. It is a <ul>, not a <table> ⚑ — the archetype is named table because of how it collapses, not because the markup is tabular; there are no column headers and no row headers, so a real table would be a worse structure. The whole row is the link and the target ⚑ — 80 px tall — and the thumb is aria-hidden inside it ⚑ so the row announces once. Caption 13.4:1; number 5.4:1.
Repeating items — images[]: as 1 Grid; designed for 6–48; reordering renumbers ⚑.
