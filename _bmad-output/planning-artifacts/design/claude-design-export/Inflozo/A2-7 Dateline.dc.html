The awkward stack: a dateline bar above a masthead that already carries a date. Height is forced to Compact 40 by the category's multi-row rule, and the sidebar adds a second note here — Meta: None is recommended when the header below shows a date. Recommended, not enforced: the bar's date is the issue's, the masthead's is today's, and there are mastheads where both belong. The bar keeps the accent eyebrow because the masthead spends its accent on the button, not on type.

↑ Meta: Latest post date on a site with no published posts. The slot is removed, along with the hairline divider — never “—”, never today's date as a stand-in, and never an empty gap the close then floats in.
This design reads Ghost content. Flagged. A2·3 Badge's spec says a design wanting post data needs a declared binding rather than a silent lookup. This is that declaration: Meta: Latest post date reads published_at — the current post's on a post template, the newest published post's everywhere else. It is a control value the author picks, it is named in the sidebar as “from Ghost”, and Custom text is the default so nobody gets a date they did not ask for. No other A2 design reads content.
