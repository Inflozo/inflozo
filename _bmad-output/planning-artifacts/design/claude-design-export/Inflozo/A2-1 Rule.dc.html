Rule

One line on the contrast band, optically centred, close at the right end. This is A2's baseline: the least a bar can be and still be a bar, and the one that defines the band, the close control, the dismissal behaviour and the sticky offset for the whole category. It spends no accent — the band is the emphasis.

Dismissal collapses the bar's height to zero over 160 ms and the header takes its place; the sticky offset and every anchor's scroll margin recompute in the same frame. At the top of the page nothing else moves. If the reader has already scrolled, the scroll position is reduced by the bar's height in the same frame, so the words under the pointer stay put. Under reduced-motion the bar is removed instantly with the same scroll correction. It does not return for 30 days, and it returns immediately if the message is edited.

1 · The skip link stays first in focus order, ahead of the bar. The bar is furniture; it must not stand between a keyboard user and the page. 2 · The bar is a <aside aria-label="Announcement"> before <header> in the DOM. No heading — it is one sentence, not a section, and a stray h2 would pollute the page outline. 3 · The inline link is a real link with its own text; “Read it” is preceded by the sentence in the accessible name computation, so it is never a bare “click here”. 4 · Close is <button aria-label="Dismiss announcement">, 32 px box inside a 44 px hit area at every width. On dismissal focus moves to the first focusable item in the header, never to nothing. 5 · Nothing about the header changes. The bar is not announced as a live region: it is present at page load, so it is read in document order rather than interrupting. Contrast · Carried text on the contrast band is 13.9:1 in Paper light and 12.6:1 in Paper dark. The 50%-opacity underline is decoration, not the affordance — the link is also distinguished by weight.

SPEC · A2·1 RULE · full text in “A2 Announcement Bars — Spec.md”
Content fields message (rich text, req, ≤ 120 chars, bold and one inline link allowed) · messageShort (text, opt, ≤ 48 — used ≤ 767) · linkLabel + linkUrl (opt pair, ≤ 24 chars) · dismissible (bool, default on) · audience (enum) · dismissMemory (enum). Unused category fields — headline, body, image, endsAt, messages[] — are kept, not shown, and reappear if the user switches to a design that displays them.
Controls · data Background role (universal): Contrast · Surface · Accent. Vertical spacing (universal): Compact 36 · Comfortable 44 · Spacious 56. Alignment: Centred · Left. Link style: Inline link · Underlined text · None. Placement: In flow · Sticky. Dismissible: On · Off. Universal trio outside the list: Background role · Vertical spacing · Top divider (locked). Visibility gains Schedule (Always · From · Until · Between dates) and Shows on (All pages · Home only · Posts · Pages); Preview as is removed — previewing is the editor’s View as.
Data: nothing from Ghost except member state, which decides whether this reader is in the targeted audience. Members disabled in Ghost → the audience control collapses to Everyone and says why. Empty message → the bar does not render at all; a bar with no sentence is not an empty state, it is nothing.
Responsive · empty · a11y · flagged 1440–768 identical but for padding and the close inset; one line, centred. ≤ 767 the bar grows to 48 for a 44 px close; messageShort is used if set, otherwise the sentence wraps and the band left-aligns, two lines maximum. No link → the sentence sits alone, still centred. a11y: aside labelled “Announcement” before header, skip link still first, close is a labelled button, focus moves into the header on dismissal.
