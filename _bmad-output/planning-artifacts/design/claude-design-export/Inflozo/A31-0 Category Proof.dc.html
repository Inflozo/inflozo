A31 Error and Utility — the category

Ten designs for three pages: the 404, the 500 and the private-site gate. Each design draws all three from one field list, so a publication picks an arrangement once and gets a coherent set — which is the only way a category of whole pages can behave like a category of sections.

The fact to read first is what each page is allowed to touch. The 404 may query Ghost freely, the 500 may query nothing at all, and the gate may query nothing the visitor is not yet entitled to see. Three of the ten have material one or two of those pages cannot give them; each hides what is missing and still renders as itself, saying so on the frame.

This frame carries what belongs to the category rather than to any one design: the four questions §8 asked, the three pages anatomised, the tokenisation proof, the stress frame, the roster with its ten structural descriptors, the shared field list, the item rules for the three authored lists, the component inventory and the findings for the architect. The per-design frames are A31-1 … A31-10, and the written specification is A31 Error and Utility - Spec.md.

THE FOUR QUESTIONS §8 ASKED, ANSWERED
1 · 404, 500 AND THE GATE — AND WHAT NAVIGATION EACH KEEPS
The 404 keeps everything ⚑ — header, nav, search, footer, and the member pill if the reader is signed in. A 404 is a page of a working site: the request failed, the site did not, and stripping its chrome would tell the reader otherwise.The 500 keeps the site title as text and one link to / ⚑. Nothing else. Navigation is data, the footer is navigation, search is a request, the member state is a query — and on a 500 the data layer is the suspect. The wordmark is drawn as text rather than as @site.logo ⚑, because a logo is a file URL from settings.The gate keeps the lockup and nothing else ⚑ — no nav, no search, no post titles, no footer. Ghost would give it all of them; the category refuses them, because each describes the site to a visitor who has not been admitted to it. The one optional line is the site description, which Ghost’s own private page shows.
2 · THE GATE’S FORM STATES
Four states, one geometry: empty, focused, filled, wrong password. Empty is the state to design for — almost every visitor sees only that one.Wrong password is a fresh server render, not an inline check ⚑. Ghost re-renders private.hbs with its own error string; the field comes back empty (Ghost does not echo a password) and focus returns to it. The message sits above the label so it is met before the input in reading order and in focus order.There is no themed submitting state ⚑. The form is a native POST to Ghost's own /private/ route, with no action attribute drawn ⚑ — Ghost supplies the destination and the return path — so the browser owns the wait: the button keeps its resting look and the page navigates. A spinner would need a module the registry does not have — the closest is member-form, which posts to the members endpoint and is the wrong one. That is a finding, not a new module.The message is Ghost’s string and never a field ⚑, and it is drawn in the text colour on the plate under a hairline — never in red: no pack has an error token, and inventing one would fail in the other eleven.
3 · WHETHER SEARCH APPEARS ON A 404 — SETTLED AGAIN, 30 AUGUST 2026
A31 draws no search form of its own ⚑ — struck in the design patch pass. The 404 renders the site header, and the search a reader uses there is the Headers category’s own Search control, on the header the publication already chose. A31 drew a second one, in the page, and two search fields on one page is one too many.And there is nowhere for A31’s field to post to ⚑. The search page it assumed belonged to a category that has since been deleted, so a form of A31’s own would submit to a route that may not exist — a 404 answered with a 404, which is the worst outcome this category can produce.What went with the field: every design’s Search on the 404 row, the search placeholder field, the two translation-catalog words that named the field, and the read-only What search reaches row. Nothing was added in its place — the block simply closes up, and the recovery links are what a lost reader now has.
4 · WHAT A 500 CAN RELY ON RENDERING
Its own words, the site title as text, and one link to / ⚑. That is the whole list. No {​{#get}​}, no navigation, no member state, no settings image, no search, no footer — because a 500 may be the data layer failing, and every query is a second chance to fail.The ceiling is lower still ⚑: if the theme itself is what failed, Ghost serves its own built-in error page and nothing designed here renders at all. A31 cannot design that page and does not pretend to. What it can do is make the theme’s own 500 depend on nothing.Three designs have material a 500 cannot give them ⚑ — 7 Cover (a file is a settings value), 8 Elsewhere (its rows are a query), 9 Directory (its items are navigation). All three still render as themselves and hide what is missing, with the 500’s copy set, and annotate it. No design turns into another design — the hand-offs A31 used to declare are retired in the design patch pass ⚑.

THE SIX HARD CASES, AND WHAT THE CATEGORY DOES
A status code that is neither 404 nor 500. 429, 403, 502 — Ghost hands the template whatever happened. The chip draws Ghost’s code and message verbatim and the copy set falls back to the 500’s ⚑, because “something went wrong at our end” is true of all of them and “we can’t find that page” is not.A 106-character heading. It wraps and is never clipped, in all ten ⚑ — including 10 Display, where the numeral holds its column and the heading wraps in the other. The only clipped string in A31 is a button label, at 30 characters, A18·3’s rule.Six authored links, two of them a full line long. The row wraps to three lines; 4 Boxed rules them and drops the URLs below 767; 5 Panel’s column takes them without stacking. None of the ten truncates a link label ⚑ — a shortened destination is a wrong destination.A site with no navigation at all. New publications have none. 9 Directory hides its columns and draws its own message alone ⚑ — it does not become another design, and the panel may advise that 1 Centred suits a site with no navigation. Every other design is unaffected, because the header’s nav is A1’s and its absence is A1’s problem.A publication with no authored links and no image. Every design still renders a heading, a sentence and one button ⚑ — that is the floor, and it is why the heading has a default in all three copy sets.A visitor who mistypes the password four times. Nothing in the theme counts attempts ⚑ — there is no module for it and no data to read. Each attempt is a fresh render of the same page with Ghost’s message; rate limiting is Ghost’s and is invisible to the theme.
REFUSED CATEGORY-WIDE · EACH WITH ITS REASON
A drawn illustration ⚑ — the obvious 404 idiom, and it cannot survive the library’s first rule: an illustration is not re-skinnable by tokens and the user cannot author one. 7 Cover’s photograph is the tokenisable answer — an authored file under a derived scrim.A soft 404 that renders the archive below the message ⚑ — a page that looks like it worked. It also cannot exist on a 500, and a design that can only draw one of the three pages is not a design in this category.An automatic redirect after a few seconds ⚑ — it needs a module the registry does not have, and it takes the decision away from a reader who may want to read the URL they mistyped.“Did you mean …?” from the URL ⚑ — Ghost offers no fuzzy match, so the suggestion would be invented. The recovery list is the honest version of the same intent — destinations a publication chose rather than a guess.A search form of this category’s own ⚑ — struck on 30 August 2026: the 404 renders the site header, so search there is the Headers category’s control, and there is no search page for A31 to submit to.A member greeting on the gate ⚑ (the visitor is not signed in and cannot be) · a themed 503 or maintenance page ⚑ (Ghost’s is not themable, so a design would never render) · red as an error colour ⚑ (no pack has an error token) · a countdown, a retry timer or an attempt counter ⚑ (no data, no module) · a per-item control of any kind ⚑.

Ten authored field groups — the first six multiplied by three pages — one authored list, and six things read from Ghost. A design may draw as few as five: 10 Display is a code, a heading, a sentence, a button and a link. Four fields are drawn by exactly one design each — the image group (7), postsLabel (8), directoryLabel (9), gateDisplayWord (10) — and all four are stored by the other nine ⚑. The copy set is the field that makes the category work: because all three pages’ words are stored at once, a publication that turns privacy on for a week does not have to write the gate from scratch and then lose it ⚑.

THE ONE AUTHORED REPEATER · links[] · WHAT THE SIDEBAR DOES WITH IT
THE ITEM LIST · ADD, REMOVE, REORDER
Three authored repeaters in the category ⚑ ⚑: links[], the recovery list, drawn by eight of the ten. 8 Elsewhere’s rows and 9 Directory’s items are authored lists too ⚑ 30 August 2026, by the owner’s ruling — posts[] and directory[], hand-written by the publication and hard-coded by the build, each with Add, Remove and drag reorder on P0·3. A31 queries Ghost for nothing, so there are three authored repeaters in the category, not one — and each panel draws what that costs: a written list goes stale when a page is renamed or removed.Add an item sits at the foot of the list in the sidebar — “+ Add a link”. A new item arrives with content, never as an empty shell ⚑: label “The archive index”, URL /archive/. It lands last, because the list is a reading order and a new item’s place is the author’s decision, not the panel’s.Remove is a row action on the item. Removing the last one is allowed ⚑ — the minimum is zero — and at zero the list, its label and its hairline all leave together and the design closes up. Nothing reserves the space, and no design shows a placeholder row.Reorder is a drag on the sidebar rows, and order is meaningful ⚑ — first is the destination the publication most wants a lost reader to take. 4 Boxed’s ruled rows and 5 Panel’s column read top to bottom; 1, 3, 6, 7 and 10’s wrapping rows read left to right, then down.
COUNTS, FIELDS AND WHAT AN EMPTY FIELD LOOKS LIKE
Minimum 0, maximum 6, designed for 2–4 ⚑. At 1 the row does not stretch to fill the measure. At 5–6 the wrapping rows go to two or three lines and 5 Panel’s column simply gets taller. Above 6 the sidebar’s Add is disabled with the reason shown — a recovery list longer than six is a navigation menu, and that is 9 Directory.Inside an item the user edits content only ⚑ — the label and the URL, and nothing else. No per-item size, weight, colour, order-number or emphasis. Selecting a link on the canvas opens those two fields and closes.The label is required and the URL is required ⚑ — a link with no destination is not a link — but 4 Boxed draws the URL as text and the others do not, so a long URL is only visible in one design, and there it is dropped below 767.Design controls apply to every item at once ⚑. “Make the third link bigger” is not expressible, by construction: a control writes one value onto the section and the stylesheet reads it. A list where one item needs to be louder is a list with a first item, and the fix is order.

FINDINGS FOR THE ARCHITECT · EIGHT, SEVEN OF THEM NEW

The rule that required itOne control name means one set of values. The side-to-side axis is new to A31 (owner’s ruling, 3 September 2026): a wide photograph cropped into a tall frame loses its sides, and a vertical-only control has nothing to say about which side survives.
Where the control lives in A317 Cover is the category’s only image slot — the union’s image group is required there and stored, undrawn, by the other nine. The control sits in that design’s Image Picker popover and points at P0·9 for its values; no A31 panel enumerates them.
Ghost never sees thisFocus is a hint the compiler resolves into the crop the theme ships with. The project stores the choice, the compiler resolves it, and nothing about it reaches Ghost or comes back — which is why it is a control and not a data binding. It declares no behaviour module, so this design’s no-JavaScript line is unchanged: core and nothing else, pixel-identical with JavaScript off.
