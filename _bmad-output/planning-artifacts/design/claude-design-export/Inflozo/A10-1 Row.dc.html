A10 STATS AND NUMBERS · DESIGN 1 OF 15 · PAPER PACK · THE DEFAULT · EIGHT CONTROLS

Row

Two, three or four stats side by side across the 1,296 content width, hairlines in the gutters, values on one baseline. The design a site gets when it types “stats” into the picker, the one A10-0's stat component was drawn for, and the design seven others hand off to.

It is also the only design in A10 that carries eight controls — the widest list in the category, and still well inside the PRD's ~15 — because it is the design where all four of §8's settlements are visible at once: the count, the units, the source line and what happens to a cell with no label. Everything else in the category is a rearrangement of this row, and every rule it establishes is cited rather than restated fourteen times.

ACCESSIBILITY · A SECTION WITH NOTHING TO OPERATE <section aria-labelledby> named by the title, an <h2>; the row a <ul> of three <li>; each stat one <p>. The value and the label are two <span>s in one paragraph, so the announcement is “41,800 readers on the Thursday letter” and not two fragments a reader has to join. The value is not a heading at any size, and the label is not an <abbr>, a <dt> or a caption. The prefix and the suffix are read as part of the value because they are inline spans in the same run: “62%” is announced as sixty-two per cent by every screen reader tested against a plain percent sign. A word suffix is announced as written — “3.4 hrs” is read “three point four hrs”, which is why the field takes what the site types rather than an abbreviation the theme expands. ⚑ Flagged: no aria-label is written over a value, because a label that says “3.4 hours” while the page says “3.4 hrs” is two different sections. One tab stop at most: the link. With no link and no source URL authored the section contains nothing focusable at all — no tab stop, no role, no live region, no state to announce. The dividers are decorative border on a <div>, never <hr>. Contrast: value 15.8:1 light / 15.1:1 dark, label 5.6:1 / 6.0:1, divider 1.3:1 (decorative), link text 15.8:1 / 15.1:1 with the underline at 3.3:1 / 6.3:1, focus ring 3.3:1 / 6.3:1. In forced colours the dividers survive as system borders and the label stops being quieter than the value, which flattens the hierarchy to size alone — stated, not corrected. Print and screen are the same drawing. Reduced motion changes nothing, because nothing moves. The only transition in the design is the link underline's 160 ms thickening, which is instant under reduced motion and does not change what the link is.

STATS · the item list · outside the design’s listStats is the P0·3 item list: Add stat arrives with content — value 100, label “What this number counts” — Remove is never disabled, drag to reorder, per-item content only. Per item: value ≤ 12 · prefix ≤ 3 · suffix ≤ 6 · label ≤ 60. note, prev and share are held and not offered here. Value source: Authored · Member count · Paid member count. At Member count the value renders Ghost’s {​{total_members}} string verbatim — “1,200+” in, “1,200+” out, no maths and no formatter, which is the category’s own no-formatter rule — prefix and suffix are disabled and the label stays authored. {​{total_paid_members}} is offered only when the site has paid members enabled. Eight is the ceiling of stats[], raised from six in this pass: “Eight numbers is as many as a reader holds in one look. A ninth is a table, and a table is a different section.” 3 Grid is the only design that draws eight; everywhere else seven or eight authored names it. Seven or eight authored → the panel names 3 Grid; Count still draws two, three or four.
EDITING · the P0 primitivesValue, prefix, suffix and label edit inline on canvas, selected where they are drawn rather than only in the repeater. The value raises no marks toolbar — it is plain text, so bold, italic and a link inside a figure are withheld rather than offered and refused. Eyebrow, title, sub, source and the link label take the P0·1 toolbar — bold · italic · underline · link, the popover carrying open-in-new-tab and rel nofollow · noreferrer · sponsored. A value bound to a member count is not inline-editable: clicking it says “Edit in Ghost”, because the figure is the site’s member list and not a word anyone typed here. sourceUrl and linkUrl open the Ghost-aware Link Picker; the section link takes an optional P0·2 icon before or after its label, off by default — the same picker the stat slots use.
BEHAVIOUR · from the fixed registrycount-up, from the fixed registry, and only at Count up On. Its own degradation is the argument: “The final value renders as static text — it is already in the HTML before JS ever runs.” JS off, reduced motion and assistive technology all get the figure rather than the animation, and the module does not re-run on the way back up the page. Edit-safe: it does not run while the section is edited, so every frame here is still a resting state. At Count up Off — the default — this design declares no module at all: the divider is a border, the label-block equalisation is a grid row, and the three-to-two and one-column steps are media queries.
DATA · Ghost’s two member helpers · outside the design’s listTwo figures in A10 can come from Ghost, and both are public theme helpers: {​{total_members}} and {​{total_paid_members}}, each rendering a pre-rounded string. They are reached from the item’s Value source and not from a “Populate from…” panel — there is no list to populate. Everything else is authored in this section. Refused on record: a post count from a tag (a number nobody wrote and nobody checks), any admin-API figure — opens, revenue, growth — a live figure from a third party, and the four ornaments: sparkline, dial, donut, pie. 9 Bars’ single proportional bar is as far as A10 goes.
