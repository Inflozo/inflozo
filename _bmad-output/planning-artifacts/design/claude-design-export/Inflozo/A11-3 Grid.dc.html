Grid

Six to eighteen logos in rows of equal cells, with or without a hairline matrix around them. This is the design §8.1 was settled for: it is the only one in A11 that draws more rows than it has counts, so the wrap order, the row gap and the short last row are all visible on its primary frame at once.

It takes seven controls — §7.6's ceiling, and the only design in A11 at it — because the last row needs a control of its own and the hairlines need one too. It also carries A11's one forced control value: at Cells Hairlines the last row is Left whatever Last row says.

ACCESSIBILITY · A GRID THAT IS NOT A TABLE The wall is a <ul> of <li>, laid out with CSS grid, and never a <table> — there is no header row, nothing compares down a column and the number of columns changes with the width. A11 carries A10·3's refusal forward verbatim. The rows are not marked up as rows either: the list is one flat list of twelve items and the grid decides where they land, so a screen reader hears twelve names and not four groups of three. Reading order is authored order at every width and every count, because the wrap is the grid's own and nothing uses order, grid-area or dense packing. The last row's Centred value is justify-content on the final row's own container and moves nothing in the DOM. The hairlines are decorative border on the <li>, never <hr> and never a role, and they carry no meaning that the layout does not already carry. In forced colours they survive as system borders and the plate survives as a system-bordered box. Tab stops: one per linked logo, plus the section link. The focus ring is on the box at Cells None and on the matrix cell at Cells Hairlines, so it never straddles a hairline. No behaviour, no state, no live region; eighteen logos is eighteen tab stops at most and there is no roving index or skip link, because eighteen links in a list is an ordinary list. Contrast: title 15.8:1 light / 15.1:1 dark, eyebrow and note 5.6:1 / 6.0:1, hairline 1.4:1 / 1.6:1 decorative, link underline 3.3:1 / 6.3:1. A logo takes no ratio. At 400% zoom the grid is two across, the hairlines follow it, and nothing overlaps or scrolls sideways. Reduced motion changes nothing, because nothing moves. Print keeps the matrix and the last row's forced Left; a printed page has no dark mode, so no plate is printed.

EDITING · the P0 primitivesEyebrow, title, sub, note and the link label edit inline on canvas with the P0·1 toolbar — bold · italic · underline · link, the link popover carrying Open in new tab and rel nofollow · noreferrer · sponsored. linkUrl opens the Ghost-aware Link Picker, and the section link takes an optional P0·2 icon before or after its label, off by default. alt is edited in the item row rather than on canvas, being the one required string this category never draws. Nothing here is Ghost-owned, so nothing answers “Edit in Ghost” — every word is authored in this section and every mark is a site upload.
