SOCIAL HANDLES · GHOST ≥ 6.36 ⚑Nine handles and a website, not two: facebook · twitter (X) · linkedin · threads · bluesky · mastodon · tiktok · youtube · instagram · website. This corrects the category’s founding fact ⚑ — “two networks” was 5.x. Version-gated: on a site below 6.36 only Facebook, X and the website exist and the rest of the row is not drawn. The author’s own fields are read, never the sitewide fallback ⚑ — social_url falls back to the site’s Facebook and X, which would print the publication’s accounts under a writer who filled in neither. There is no loop over the handles: nine checks, and an absent handle reserves nothing.

WHAT THIS PANEL SETTLESTwo controls are conditional and both say why. Row height: Compact is disabled while portraits are shown; Group by letter is disabled unless the order is alphabetical. Neither silently changes another control's value — they disable with a sentence, which is the library's rule for conflicts.Order defaults to Name A–Z here ⚑ and to Most posts elsewhere. A directory that a reader scans for a name is sorted by name; the shared control is the same control, with a different default per design.Cut: a sortable header ⚑ (that is client-side sorting, and no module in the registry does it — finding 4), a search field (A23's), a "joined" column ⚑ (created_at is an account date, not an editorial one), and a latest-post column ⚑ — see finding 2.
