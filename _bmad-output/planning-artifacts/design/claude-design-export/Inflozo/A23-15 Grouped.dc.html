WHAT THE GROUPS SETTLE
A tag row is not a post row ⚑ — name and post count, 17 px semibold, no date, no excerpt, no reading time. Dressing a tag as an article is the commonest grouped-search defect.Group order is authored, not ranked ⚑. Ghost gives a theme no relevance score across object types, so “best match first” would be an invented ranking. The control offers two orders and both are stated as arrangements, not relevance.Three rows a group, then a way in. A “See all 9 in Posts” row rather than a longer group ⚑ — the same call 2 Overlay makes about its panel, for the same reason: a long group buries the groups below it.

Groups appear and disappear as the query changes ⚑, which is the state behaviour this design owns: three groups for one word, one for another, and no empty headings ever. Before a query there is exactly one group — featured — because grouping three featured posts by object type would be a fiction ⚑.

THE SEARCH SOURCE · SEVEN ROWS · IDENTICAL WHEREVER RESULTS ARE DRAWN · NOT COUNTED
What it searches
Posts and pages▾
Posts · Posts and pages · Posts, pages and tags · Everything, including authors. Ghost decides what a theme can reach; this row says which of it this section asks for ⚑.
Search in
Titles and excerpts▾
Titles and excerpts · Full content. Full content is available here and is not in Ghost’s own bundle ⚑ — A23’s index is client-side over the Content API, which can return plaintext. It costs index size: roughly 4–8 kB a post, so a 400-post archive fetches a few megabytes before the first query. Titles and excerpts is the default, and this row is what the read-only line below reports.
Before a query
Recent searches, then featured▾
Recent searches, then featured · Featured posts · Latest posts · Nothing. Recent searches are the reader’s own and never leave their browser ⚑; a first visit falls through to the second value. “Most read” is gone ⚑ — Ghost gives a theme no view counts, so it was a promise the platform cannot keep.
Start searching after
3 characters▾
2 · 3 · 4 characters. A1·9’s three-character minimum and 200 ms debounce, carried ⚑.
How many results
20▾
10 · 20 · 50 · All matches. The cap is the section’s, not Ghost’s — the count line always names the true total ⚑.
Match highlight
MarkedPlain
A real <mark> at 16 % accent, 22 % in dark, in the title and the excerpt and never in the meta ⚑. At Plain it is absent from the DOM rather than untinted. Promoted here from 11 Thumb Rows, so every design that draws a result governs it in the same row ⚑.
What is indexed
Title, excerpt and slug🔒
Read-only, and it follows Search in ⚑. At Titles and excerpts it reads title, excerpt and slug; at Full content, title, excerpt, slug and body text. emptyText’s default follows the same value, which is why that sentence is a field and not a string.
EDITING · THE P0 PRIMITIVESThe four group labels edit inline — postsLabel, pagesLabel, tagsLabel, authorsLabel — with the P0·1 toolbar, in place, at their drawn size ⚑. Post, page, tag and author names and their counts are Ghost’s ⚑ — “Edit in Ghost”. countLabel, seeAllLabel, emptyHeading, emptyText, emptyLinkLabel, recentLabel and suggestLabel are edited through the P0·6 switcher: No query · Results · No matches ⚑.
DATA · GHOST’S OWN, AND NEVER AN AUTHORED LISTGhost posts, pages, tags and authors by scope: no Add, no Remove, no drag ⚑. An empty group is absent, label and all ⚑. No Member Visibility row ⚑ — every row here is a link.

WHAT THIS PANEL SETTLESGroup counts here are the query’s; 13 Facet Rail’s are the archive’s ⚑. Two designs, two numbers, both named — because a reader cannot tell them apart and a developer must.No “which groups” control ⚑ — that is the source group’s scope. Search posts and there is one group; search everything and there are four.Six controls and no seventh. Cut: thumbnails (11 Thumb Rows), density (rows-per-group is the rhythm), a per-group control of any kind — a control writes one value onto the section, so “posts bigger than pages” is not expressible and asking for it is asking for two designs ⚑.Padding retired into the trio’s Vertical spacing; Result meta arrived; the no-JS claim that the route could render these groups server-side is struck ⚑ — Ghost has no server-side search, so with JavaScript off there are no groups at all.
