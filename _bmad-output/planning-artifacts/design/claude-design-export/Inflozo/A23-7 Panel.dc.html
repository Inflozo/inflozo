WHAT THE SEVEN STATES SETTLE FOR THE WHOLE CATEGORY
The count line is the announcement. Where results replace in place without a navigation it is a visually-hidden aria-live="polite" region as well as visible text ⚑. Where the query was a page navigation there is no live region — A34’s rule.One row, two densities ⚑ — the suggestion row is title plus “section · author · date”; the result row is that row with an excerpt. A1·9’s accessible name, matched.No matches is a content state, not an error. No red, no icon: the query in the heading, one line of why, the section chips as the way out, and a line naming what is indexed ⚑ — which is now whatever the source group’s Search in row says it is.The no-JS floor is the field and the archive link ⚑ — Ghost cannot read ?q= or search server-side, so a GET to /search/ lands on a page whose results the same client module renders. No JavaScript, no results, in any of the fifteen.

The plane’s top edge never moves ⚑ — every state grows or shrinks downward, so a reader typing does not watch the object they are typing into slide up the page. The plane keeps its 48 px padding at one result: shrinking the padding with the content would make a one-result plane read as a different component.

THE SEARCH SOURCE · SEVEN ROWS · IDENTICAL WHEREVER RESULTS ARE DRAWN · NOT COUNTED
What it searches
Posts and pages▾
Posts · Posts and pages · Posts, pages and tags · Everything, including authors. Ghost decides what a theme can reach; this row says which of it this section asks for ⚑.
Search in
Titles and excerpts▾
Titles and excerpts · Full content. Full content is available here and is not in Ghost’s own bundle ⚑ — A23’s index is client-side over the Content API, which can return plaintext. It costs index size: roughly 4–8 kB a post, so a 400-post archive fetches a few megabytes before the first query. Titles and excerpts is the default, and this row is what the read-only line below reports.
Before a query
Recent searches, then featured▾
Recent searches, then featured · Featured posts · Latest posts · Nothing. Recent searches are the reader’s own and never leave their browser ⚑; a first visit falls through to the second value. “Most read” is gone ⚑ — Ghost gives a theme no view counts, so it was a promise the platform cannot keep.
Start searching after
3 characters▾
2 · 3 · 4 characters. A1·9’s three-character minimum and 200 ms debounce, carried ⚑.
How many results
20▾
10 · 20 · 50 · All matches. The cap is the section’s, not Ghost’s — the count line always names the true total ⚑.
Match highlight
MarkedPlain
A real <mark> at 16 % accent, 22 % in dark, in the title and the excerpt and never in the meta ⚑. At Plain it is absent from the DOM rather than untinted. Promoted here from 11 Thumb Rows, so every design that draws a result governs it in the same row ⚑.
What is indexed
Title, excerpt and slug🔒
Read-only, and it follows Search in ⚑. At Titles and excerpts it reads title, excerpt and slug; at Full content, title, excerpt, slug and body text. emptyText’s default follows the same value, which is why that sentence is a field and not a string.
EDITING · THE P0 PRIMITIVESEyebrow, heading and note edit inline with the P0·1 toolbar. Row content is Ghost’s ⚑ — “Edit in Ghost”. The state strings — countLabel, emptyHeading, emptyText, emptyLinkLabel, recentLabel, suggestLabel — are edited inside the plane through the P0·6 switcher: No query · Results · No matches ⚑. The archive link opens the Link Picker.
DATA · GHOST’S OWN, AND NEVER AN AUTHORED LISTGhost posts and pages by scope: no Add, no Remove, no drag ⚑. No Member Visibility row ⚑ — no CTA on the plane.

WHAT THIS PANEL SETTLESFive controls, not six. There is no Field width value: the plane’s column decides it ⚑, exactly as the column does in 4 Split Head. Adding one would let a designer put a 400 px field in a 1,296 px plane, which is the arrangement’s worst state.No result density value either ⚑ — a plane has one internal rhythm, and its padding sets it. Density plus plane padding is two controls arguing about the same whitespace.Depth is the only control in A23 that a mode overrides. It is stated in the help text rather than silently applied, and it is A29·4’s rule for every card in the library. Padding retired into the trio; Plane padding stayed, because one is the space around the object and the other is inside it ⚑.
