Ghost's signup endpoint will not accept a plain form submission — tested against both live servers — so a field without script takes an address and loses it. P0·4's notice replaces the field and button at the form row's own height — 46 px here, 48 px at ≤ 767 — so the hero's height does not change and nothing below it moves. The headline stays, the note stays, and the notice is plain text rather than an alert: nothing has changed for this reader, so there is nothing to announce. What was withdrawn is only the claim that the form works without it. This is A3·4's frame in a hero, with the same wording, because the two designs share the form and should share its failure.

The form is not given a heading of its own: it has the hero's, and aria-label="Subscribe to Orbit Weekly" on the <form> names it for anyone who reaches it out of context — A3·4's approach, which it needed because it had no heading at all. 2 · A real visually-hidden <label>Email address</label>, never a placeholder as the label. type="email", autocomplete="email", inputmode="email", required; aria-invalid on error with focus held in the field. The button is a <button type="submit"> whose visible label is its whole name, disabled while submitting. 3 · The note is both the aria-describedby target and the aria-live="polite" region, so the error and the confirmation are announced in the place the terms were read. One region, three messages, no toast. The focus ring · suppressed on the field in favour of a 1.5 px accent border, because the library ring at 2 px with a 2 px offset collides with a button 8 px away. A3·4 documented this departure and this design repeats it rather than solving it differently. The button keeps the standard ring. Contrast · placeholder 5.1:1 light / 5.9:1 dark · note 5.4:1 / 6.4:1 · error at 13 px / 500 in text 12.1:1 · field border 1.4:1 and decorative, since the field's fill always differs from the ground · button label on accent 3.2:1 light and 8.1:1 dark, the flagged pack finding in A4-0. No red · the seven roles contain no error colour, so the error is carried by weight, position and words. A theme that reached outside the token set for a red would be a theme that cannot be re-skinned.
