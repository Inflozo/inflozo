P0·2 · Icon slot + Icon Picker

A user can never place an icon anywhere but an icon slot a design declares. A slot is filled (shows its icon) or empty (a dashed 20 px placeholder, visible only while the section is selected). Clicking a slot opens the Icon Picker; clicking a filled slot while its section is selected opens the slot popover.

The set is Tabler Icons: one MIT library whose brand-* glyphs cover the social rows — Lucide 1.0 removed all brand icons, so the PRD reference is amended here, once, for the whole library.

Four things and nothing else: swap, Size (Small · Medium · Large), Colour role (Text · Muted · Accent · On-accent), Remove. On-accent exists for icons sitting on accent or contrast fills and is contrast-checked per pack; a role failing AA on its ground is disabled with its ratio shown, per the library rule. Remove empties the slot back to its dashed state.
