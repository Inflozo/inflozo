Everything is centred on one axis and nothing is off it — the design's whole discipline. The measure is Medium 720 for the headline, and the sub is held to 560 px inside it rather than filling the same width: a standfirst as wide as the headline reads as a second headline. Padding is Comfortable 96 top and bottom, the page margin is 72, and the hairline above is A1·1's, not the hero's. The header sits on its own ground; this design's mode is Below, so an A1·4 Overlay header has no picture to sit on and renders on its own ground — A1·4's own no-image state (the rule that no design ever turns into another design), exactly as drawn.

1 · The eyebrow is a <p>, not a heading and not part of the h1's accessible name — “Issue 48, The personal page never disappeared” is not the page's title. It is authored in sentence case and uppercased in CSS, so a screen reader hears the words rather than the letters. 2 · The headline is the page's one <h1> on home, pages and custom routes. The hero is a plain unlabelled <section>: it is the first thing in <main> and the h1 announces it, so a landmark label would say the same thing twice. 12.1:1 light, 11.8:1 dark. 3 · Both actions are links styled as buttons — they go somewhere, so they are <a>, and each label is its whole accessible name. 46 px tall by construction, 48 at ≤ 767. Focus order is eyebrow, headline, primary, secondary; there is no CSS re-ordering at any width, so it matches reading order everywhere. 4 · The note is plain muted text tied to nothing — it is not the primary action's description, because a button whose name is “Subscribe” and whose description mentions unsubscribing reads as a contradiction when both are announced together. Flagged as mine. Contrast · headline 12.1:1 / 11.8:1 · sub and note muted 5.4:1 / 6.4:1 · primary label on accent 3.2:1 light and 8.1:1 dark — flagged, see A4-0’s pack-level finding on Paper’s accent · secondary label 12.6:1 with a decorative border. On the Contrast ground: headline 13.9:1, carried sub at 72% 7.6:1, primary label on the light surface 13.9:1. Zoom and reflow · at 200% text zoom the measure formula recomputes and the headline rewraps; nothing is clipped and no fixed height exists anywhere in the design. The centred axis is the same at every zoom, which is why the design has no maximum height.
