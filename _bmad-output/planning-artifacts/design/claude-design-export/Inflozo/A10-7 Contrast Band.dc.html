Contrast Band

1 Row inverted onto the contrast token. Switching between this design and 1 Row changes nothing but the colours — the same 416 division, the same baseline, the same 48 px head gap, the same 32 px source gap — which is the tokenisation claim at its hardest and the fourth category to make it.

The reason a stats section wants a band is that numbers at 52 px on an inverted ground are the loudest thing a page can do with type alone. The reason it is one design and not a control on all fifteen is that a band changes every colour in the section, and a section that can be inverted at will is a section whose contrast has to be re-checked at every value of every other control.

ACCESSIBILITY · A BACKGROUND, NOT AN ELEMENT 1 Row's structure unchanged: <section aria-labelledby>, an <h2>, a <ul> of <li>, one <p> per stat. The band is a background colour on the section, not an element, not a region and not a landmark — nothing about it is announced, because a change of colour is not a change of context. Contrast, all five derived values: value and title 15.8:1 light band / 14.7:1 light-in-dark, muted 8.7:1 / 6.0:1, hairline 2.4:1 (decorative), link text 15.8:1 / 14.7:1, focus ring 15.8:1 / 14.7:1 — the strongest ring in A10. The accent is disabled at 2.3:1 with the ratio shown in the sidebar, which is §7.4's rule: a value that would fail is disabled and named, never silently allowed. Forced colours drops the band and keeps every hairline, at which point this design and 1 Row are the same drawing — a user in forced colours cannot tell which of the two the site chose, and that is correct, because the choice was a colour. Print drops the band and prints the values in text on white with the hairlines kept. One tab stop at most — the link. At Count up Off no behaviour, no hover on a stat and no motion. At On the figures count in the carried colour and nothing else changes: the string is server-rendered, so a reader under reduced motion, with no JavaScript or on a screen reader is given the band exactly as it is drawn here.

STATS · the item list · outside the design’s listStats is the P0·3 item list: Add stat arrives with content — value 100, label “What this number counts” — Remove is never disabled, drag to reorder, per-item content only. Per item: value ≤ 12 · prefix ≤ 3 · suffix ≤ 6 · label ≤ 60. note, prev and share held, and no item field carries a colour: the carried colour is the section’s, so no stat can be lit differently from its neighbour. Value source: Authored · Member count · Paid member count. At Member count the value renders Ghost’s {​{total_members}} string verbatim — “1,200+” in, “1,200+” out, no maths and no formatter, which is the category’s own no-formatter rule — prefix and suffix are disabled and the label stays authored. {​{total_paid_members}} is offered only when the site has paid members enabled. Eight is the ceiling of stats[], raised from six in this pass: “Eight numbers is as many as a reader holds in one look. A ninth is a table, and a table is a different section.” 3 Grid is the only design that draws eight; everywhere else seven or eight authored names it. Seven or eight authored → 3 Grid, which has no band, and the panel says so before the frame changes.
EDITING · the P0 primitivesValue, prefix, suffix and label edit inline on canvas, selected where they are drawn rather than only in the repeater. The value raises no marks toolbar — it is plain text, so bold, italic and a link inside a figure are withheld rather than offered and refused. Eyebrow, title, sub, source and the link label take the P0·1 toolbar — bold · italic · underline · link, the popover carrying open-in-new-tab and rel nofollow · noreferrer · sponsored. A value bound to a member count is not inline-editable: clicking it says “Edit in Ghost”, because the figure is the site’s member list and not a word anyone typed here. On the band the toolbar and its popovers keep their own chrome — the editor is not inverted with the section. sourceUrl and linkUrl open the Link Picker; the section link takes an optional P0·2 icon, drawn in the carried colour like everything else here.
BEHAVIOUR · from the fixed registrycount-up, from the fixed registry, and only at Count up On. Its own degradation is the argument: “The final value renders as static text — it is already in the HTML before JS ever runs.” JS off, reduced motion and assistive technology all get the figure rather than the animation, and the module does not re-run on the way back up the page. Edit-safe: it does not run while the section is edited, so every frame here is still a resting state. At Count up Off — the default — this design declares no module at all: the band is a fill, the derived muted and hairline values are percentages of the carried colour resolved in the stylesheet, and Band width is a width.
DATA · Ghost’s two member helpers · outside the design’s listTwo figures in A10 can come from Ghost, and both are public theme helpers: {​{total_members}} and {​{total_paid_members}}, each rendering a pre-rounded string. They are reached from the item’s Value source and not from a “Populate from…” panel — there is no list to populate. Everything else is authored in this section. Refused on record: a post count from a tag (a number nobody wrote and nobody checks), any admin-API figure — opens, revenue, growth — a live figure from a third party, and the four ornaments: sparkline, dial, donut, pie. 9 Bars’ single proportional bar is as far as A10 goes.
