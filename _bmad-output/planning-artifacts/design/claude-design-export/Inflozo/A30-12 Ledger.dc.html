THE DATA GROUP · THE MEMBERSHIP SOURCE, RECUT · IDENTICAL IN ALL THIRTEEN · NOT COUNTED
Which page this is
Signup🔒
Read-only. The template decides — the section reports whether it is drawing custom-signup, custom-signin or custom-account ⚑, and draws the matching arrangement.
Form wiring
data-members-form🔒
Read-only, new in this pass ⚑. The form carries data-members-form="signup" or "signin" and the drawn states are Ghost's own: Ghost writes loading, success and error onto the form element, which are sending, sent and invalid ⚑. Expired stays the query string's and already-signed-in is server-side. The sign-out button carries data-members-signout ⚑ — Ghost's only sign-out mechanism, and the answer to the "verify the attribute" note the frames carried.
Tiers
From Ghost, visible only▾
From Ghost, visible only · From Ghost, all · Off. Reads {​{#get "tiers"}​}; the user cannot add or remove a tier here ⚑ — tiers are Ghost objects and are edited in Ghost.
After the address is sent
Sent panel in place▾
Sent panel in place · Portal takes over. In place is the default ⚑ — the themed page keeps the reader where they were; Portal's own notification is the alternative.
One-time code entry
Off▾
Off (default) · On, new in this pass ⚑. Ghost's magic-link email now carries a sign-in code as well as a link and the themed sent panel said only "check your email". At On the sent panel adds a code field and its own button, under the sentHeading text. ARCHITECT: member-form registry extension, and an endpoint to verify the code against ⚑ — no module in the registry verifies a code today. No-JS: the field is absent from the DOM and the emailed link still works.
A signed-in member on this page
Membership summary▾
Membership summary · Send them to the account page. Never the signup form ⚑ — a member who lands on /signup/ has nothing to sign up for. This is the category’s member-state model, and the reason no design carries a Member visibility row ⚑.
Everything that changes a subscription
Ghost Portal🔒
Read-only. Plan changes, checkout, billing, email changes and newsletter preferences are Portal’s ⚑ — the theme draws the trigger and Portal draws the rest. This is the category’s boundary and no control moves it.
EDITING · THE P0 PRIMITIVESEvery authored string edits inline on canvas with the P0·1 toolbar — bold · italic · underline · link, its popover carrying Open in new tab and rel nofollow · noreferrer · sponsored: heading, blurb (the price sentence ⚑), ctaLabel, legal, benefits[] names and details, and every state string. Ghost-owned content is never inline-editable ⚑ — the member's name and email, the tier name, the price, the renewal date, the newsletter names and a tier's description and benefits all answer "Edit in Ghost" or show P0·1's lock pill. Every URL field opens the Ghost-aware Link Picker, Portal actions first. No fixed English visitor-facing string ships: the rescued literals above are fields with defaults, and the badge vocabulary and sending word are catalog strings. There is no Preview control in this panel and there never was one to remove — states are P0·6's switcher, audiences are View as.benefits[] is the P0·3 authored list ⚑ — drag to reorder, per-row overflow with Duplicate and Remove, Add arrives with content rather than an empty shell, Remove is never disabled, and the range line reads 0–6 · 4 used. Add disables at six with its reason in a sentence. Per-item content only: a name and a detail edit inline, and no per-item layout control exists ⚑. Tiers are the other list and are Ghost’s — no Add, no Remove, no drag.The one icon slot is the primary button’s ⚑ — P0·2's button-icon rules: Before or After the label, always Small, always the label's colour, its Size and Colour rows hidden. The list marker is the second where a design draws ticks, and it is whole-list.Member Visibility lands nowhere in A30 ⚑, and it is a judgement rather than an omission: the route is the member state. A signed-in member never sees a signup form — the Data group's "A signed-in member on this page" decides what they see instead — so a section-level Everyone / Logged out / Free / Paid row would hide a page from readers the route has already sorted. P0·4’s member-aware action editor never opens here for the same reason. Recorded in the Reconciliation notes.This design draws no eyebrow and no note ⚑, so neither row appears — the two traps the pass fixed elsewhere do not exist here, and the panel says so rather than showing a control that governs nothing.

WHAT THIS PANEL SETTLESThis is the only design in A30 with an item list in its panel ⚑ — everything else in the category is Ghost’s. The included lines are the user’s own writing, which is why they can be added, removed and reordered here and tiers cannot.A control writes one value onto the section, never onto a row ⚑. One field, one place, whatever the arrangement.Reconciled.
