WHAT WAS REFUSED HERE
A date column was considered and refused ⚑. Nothing in the item carries a date — images[] is image, alt, caption, link — and inventing one would add a fourth field to every item in the category for the benefit of one design. The finding is recorded rather than the field added.A sortable header was refused ⚑ — sorting is a client-side behaviour, the registry has no sort module (shuffle is the nearest and it randomises), and a gallery whose order the author set should not reorder itself. Owner-ruled 3 September 2026: none will exist — a module here would also have to differ from this design’s own no-JavaScript state, where a visitor gets the arranged order anyway.The thumb can be switched off entirely ⚑, at which point this design is a list of captions with a lightbox behind it — which is a legitimate picture-credits section and the reason the value exists.

A row with no caption draws its number and its thumb at full row height ⚑ — the text cell is simply empty, never “Untitled”, never collapsed. That is A16·13’s rule for an empty note cell, carried verbatim. At one image the index is one row with two hairlines ⚑, which looks like what it is: a list of one.
