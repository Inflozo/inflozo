Tag Row

The tags as the whole footer: a small label, the tags at 44 px full-height targets at reading size rather than meta size, and one link to the archive under them.

It is the footer for a site whose tags are real navigation — a publication with fifteen sections rather than three moods. Everywhere else in A26 a tag is 13 px meta; here it is 15, 17 or 19 and it is the only thing on the page.

The destination is authored and has no default ⚑ — ruled 3 September 2026. Ghost publishes no all-tags route: there is a page per tag and nothing above them, so a hard-coded destination would point at a page that may not exist, and dropping the link would take it from the owners who have built one. So the row is a Text Field and a Link Picker, and it renders only once the destination is set — it cannot ship broken, and an owner with no such page leaves it empty and loses nothing but the line.
The label keeps its default, "Browse the archive" — a label with no destination is harmless; a destination invented for the owner is not. In the panel, Archive link is greyed while the destination is empty, with the reason beside it rather than hidden or left accepting a value it will not honour.

POST FOOTERS PATCH · 30 AUGUST 2026 · WHAT CHANGED ON THIS FRAME, AND THE RULE THAT REQUIRED IT
“+N more” carries no numberThe overflow link reads “+ more”, not “+4 more”. A template cannot subtract the drawn tags from the total — it can only be told that another tag exists — so the count could only have been hard-coded. It is still a link and still not a disclosure, so the unscripted page is unchanged.
Item counts are a number pickerTags shown is a stepper, 1 to 12, default 6 — new in this pass, where the row drew Three · Six · All. The + is greyed at twelve with the reason visible: past twelve the row is four lines and stops being a gesture. The old All value is gone, which is the one thing this pass took away: a post with more than twelve tags now shows twelve and the “+ more” link. A post with fewer tags than the number draws all of them and no link.
No design ever turns into another designThe hand-off to 6 Slim is deleted in four places. An untagged post now renders nothing at all — no label, no ruled row, no reserved height — and the editor reads “This post has no tags, so this footer renders nothing. Add a tag in Ghost.” It was the only design in A26 that swapped rather than dropped, and it no longer does.
The no-JavaScript noticeNo subject in this design — it contains no subscribe and no sign-in form, so there is nothing for a designed notice to replace. The share links are real <a href> URLs and work unscripted; only the copy-link button is hidden.
Member buttons are conditionalNo subject at rest — this design draws no member action. At Blocks Everything the inherited subscribe bar carries the note, and the note is 12 Subscribe’s.

POST FOOTERS PATCH · PASS FOUR · 3 SEPTEMBER 2026 · WHAT CHANGED ON THIS FRAME, AND THE RULE THAT REQUIRED IT
The all-tags link is authored, not assumedThe row becomes a Text Field for the label plus a Link Picker for the destination — both already in the control vocabulary, nothing new invented — and the destination has no default ⚑. Ghost publishes no all-tags route, so there is nothing honest to default to, and the link cannot simply be dropped either: a site owner may well have built such a page. It does not render until a destination is set, so it can never ship broken, and an owner with no such page leaves it empty. The empty and the set states are drawn on this frame, and Archive link On is greyed with the reason beside it while the destination is empty. Finding 5 is closed — the owner's own answer, rather than either option he was offered.
An author’s post count may be shown, and a design may turn it offNo subject — the post count is 10 Big Type's alone, and no other design in A26 reads a derived figure. The ruling is recorded here because the field list is shared: the count stays, with an off switch, defaulting to Hide.
The pack supplies its contrast colours, and they are COMPUTEDEvery pack value is marked COMPUTED or AUTHORED, and on-contrast text, accent-on-contrast, dark elevation, dark hover-surface and tabular figures are all COMPUTED — the pack supplies them, so no design works out its own readable text colour for a coloured band. No subject on this frame: nothing here derives a colour for itself.
A control’s dependency is declared in its own definition, with its reasonThe dependency is declared in the control’s own definition and carries its reason, so the panel, the checker and the compiler read one source; a design never hand-draws the relationship. On this frame it covers Tags shown’s + at twelve and, new in this pass, Archive link On while the destination is empty — and this design declares no share block, so it has no destinations row.
The answers with no subject in this designThree of the answers carried into this pass have no subject here. Which section is the main feed — the project file stores it, and A26 owns no feed, no query empty state and no page-number control. Hand-picked posts keep the order the user dragged them — A26 authors no array at all, and the tags, the authors and the two neighbours are Ghost's in Ghost's order. A design may declare more than one behaviour module — this design declares none; where a design declares two, as 3, 5 and 15 do, the compiler emits the union — settled since the inventory merge.
PASS FIVE PATCH · 3 SEPTEMBER 2026 · IMAGE FOCUS IS ONE SHARED CONTROL, DEFINED IN P0·9
What changed on this frameNothing changed on this frame. Image focus has never been named in this design’s panel, control list, data fields or spec, so there was no private copy of its values here to withdraw. No control was added or removed, no default moved, and no picture, measure, type step, colour or spacing step changed.
The rule that required itOne control name means one set of values. Image focus was never a shared control: two dozen category specs each wrote out their own copy of its values, which is that rule’s worst case in the library. It is now defined once, in P0·9, carrying both axes — the side-to-side half by the owner’s ruling of 3 September 2026, which this category did not have — and a category supplies only the slot it applies to.
Where the control lands hereNowhere, and there is nothing here it could apply to. This design draws no picture at all — no avatar, no portrait, no tile — so the control has no slot to sit under and the question of narrowing an axis does not arise.
Ghost never sees thisFocus is a hint the compiler resolves into the crop the theme ships with. The project stores the choice, the compiler resolves it, and nothing about it reaches Ghost or comes back — which is why it is a control and not a data binding. It declares no behaviour module, so this design’s no-JavaScript line and its declared behaviour are both unchanged.
OPEN FOR THE OWNERNone from this design. With no picture drawn there is nothing here to decide, and the category’s two open items — whether 7 Next and Prev and 11 Portrait should now draw the control on a Ghost-owned photograph they crop, and whether an avatar’s circular crop is a subject for it — are recorded on those frames and on A26-0. Recorded here as having no subject rather than left blank.
