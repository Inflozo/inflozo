7 · Index

Every public tag, alphabetically, in newspaper columns under its initial. The design for the site that has forty topics and means all of them — a back-of-book index rather than a selection.

It is the only design in A20 that groups, and grouping is what makes it survive a large set: forty names in four ungrouped columns is a wall, and forty names under fourteen letters is a list you can scan.

The letter heads are cut in by a small script ⚑ 29 August 2026. Ghost’s templates cannot tell that the first letter changed between two tags — there is no arithmetic in a template and no way to look at the previous item inside a loop — so at Group by: Initial this design declares group-headings, the registry’s module. Without JavaScript the same names render flat and ungrouped in the same columns: every name present, alphabetical, no letter heads and no gap where one would have been. That state is drawn below.
