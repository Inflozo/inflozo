Slim

A band 128 px tall with no head, no source line and no link. The label sits beside the value on the same baseline rather than under it, which is what makes the band short: one line of text instead of two, three times across the width. A7·8's padding scale, and the design a site drops under a pricing table or between two long sections.

Eight section fields are kept and not drawn — eyebrow, title, sub, source, sourceUrl, linkLabel, linkUrl and lede — and the panel says so. A band that carried a title and a source line would be 1 Row with tighter padding, and 1 Row already exists.

The panel names Under as the position for long labels rather than capping them. ⚑ Mine. Centred is offered here and refused in 1 Row and 9 Bars. ACCESSIBILITY · ANNOTATED · A SECTION WITH NO NAME There is no <h2> and therefore no accessible name, which is the same position A9·13 and A9·15 took. The section is a <section> with no aria-label: a name invented by the theme — “Statistics”, “By the numbers” — is words a site did not write, and an unnamed region is skipped by a landmark rotor rather than announced wrongly. The panel says so: “No title. This band has no landmark name.” ⚑ Mine, following A9's precedent. The set is a <ul> of <li> and each stat is one <p>, at Beside as much as at Under. The label sitting beside the value changes the layout and not the structure, so a screen reader announces “41,800, readers on the Thursday letter” identically at both positions. The 12 px gap is a flex gap and not a space character, so there is no stray whitespace in the announced string. Nothing is focusable, so there is no focus order, no tab stop and no keyboard behaviour to state. A reader tabbing through the page passes the band without stopping, which is correct: there is nothing here to operate. This is the only section in A10 that is entirely inert. Contrast: value 15.8:1 light / 15.1:1 dark, label 5.6:1 / 6.0:1. Rules 1.5:1 on the ground, held to no text ratio. At 200% zoom the three groups wrap to two lines and then to a column; nothing is clipped, because the band's height is set by its content. Print: the band prints as drawn including its rules, which is the one A10 design where the hairlines are load-bearing on paper.

STATS · the item list · outside the design’s listStats is the P0·3 item list: Add stat arrives with content — value 100, label “What this number counts” — Remove is never disabled, drag to reorder, per-item content only. Per item: value ≤ 12 · prefix ≤ 3 · suffix ≤ 6 · label ≤ 60. note, prev and share held, along with the eight section fields this design keeps and never draws. Value source: Authored · Member count · Paid member count. At Member count the value renders Ghost’s {​{total_members}} string verbatim — “1,200+” in, “1,200+” out, no maths and no formatter, which is the category’s own no-formatter rule — prefix and suffix are disabled and the label stays authored. {​{total_paid_members}} is offered only when the site has paid members enabled. Eight is the ceiling of stats[], raised from six in this pass: “Eight numbers is as many as a reader holds in one look. A ninth is a table, and a table is a different section.” 3 Grid is the only design that draws eight; everywhere else seven or eight authored names it. Four or more authored draws the first three and the panel states it, at eight as at five — the raised ceiling changes the number in that sentence and nothing else.
EDITING · the P0 primitivesValue, prefix, suffix and label edit inline on canvas, selected where they are drawn rather than only in the repeater. The value raises no marks toolbar — it is plain text, so bold, italic and a link inside a figure are withheld rather than offered and refused. Eyebrow, title, sub, source and the link label take the P0·1 toolbar — bold · italic · underline · link, the popover carrying open-in-new-tab and rel nofollow · noreferrer · sponsored. A value bound to a member count is not inline-editable: clicking it says “Edit in Ghost”, because the figure is the site’s member list and not a word anyone typed here. This design draws no head, no source line and no link, so the values and the labels are the whole editable surface and the P0·1 toolbar is raised on the labels only. There is no URL field to open the Link Picker for, and no button to hang a P0·2 icon on beyond the stat slots.
BEHAVIOUR · from the fixed registrycount-up, from the fixed registry, and only at Count up On. Its own degradation is the argument: “The final value renders as static text — it is already in the HTML before JS ever runs.” JS off, reduced motion and assistive technology all get the figure rather than the animation, and the module does not re-run on the way back up the page. Edit-safe: it does not run while the section is edited, so every frame here is still a resting state. At Count up Off — the default — this design declares no module at all: Alignment, Label position and Rule are values on the section and the stack at ≤ 767 is a media query. At Count up On a 128 px band still holds its height — the final value is in the HTML, so nothing reflows while the figures run.
DATA · Ghost’s two member helpers · outside the design’s listTwo figures in A10 can come from Ghost, and both are public theme helpers: {​{total_members}} and {​{total_paid_members}}, each rendering a pre-rounded string. They are reached from the item’s Value source and not from a “Populate from…” panel — there is no list to populate. Everything else is authored in this section. Refused on record: a post count from a tag (a number nobody wrote and nobody checks), any admin-API figure — opens, revenue, growth — a live figure from a third party, and the four ornaments: sparkline, dial, donut, pie. 9 Bars’ single proportional bar is as far as A10 goes.
