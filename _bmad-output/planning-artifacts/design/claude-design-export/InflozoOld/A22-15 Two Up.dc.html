ONE, TWO AND MORE NEWSLETTERS
1 newsletter → one card at the grid’s left, no stretch ⚑, and the panel names 2 Card as the design meant for one. The section is not switched.2 is what the layout is built for. 3 → three of 416; 4 → two rows of two ⚑.5 or more → the panel names 10 Choice ⚑, which holds any number in one field. Five cards is five forms and no reader fills in five.

The states are per card, not per section ⚑ — this is the one design in A22 where two of them can be on screen at once, one done and one empty. Card heights are equalised by the grid, so a done card does not shorten beside an empty one ⚑; the taller of the two states sets the row.

The five state strings are edited in the state that shows them through the P0·6 editor state switcher — Empty · Invalid · Done · Subscribed · Members off — inline, in place, never a sidebar preview row ⚑. The form speaks Ghost’s own contract ⚑ new in this pass: data-members-form="subscribe" on the <form>, data-members-email on the field and data-members-name when Ask for a name is on. THE SHAPE, WHEREVER IT OCCURS Drawn, never hidden. The unavailable value is struck, the reason is one short sentence at the control and never a tooltip, and the value the design falls back to is named. The one exception is different in kind: a control this project can never offer is not drawn at all and the panel says why — A22 claims that exception nowhere.
A control switched off by another is greyed, with the reason beside it One case, and it is a change — the twin of 10 Choice's. With the cadence half of the meta line deleted, the generated line is one word drawn only on a paid letter; on a site with no paid letter Card meta: Show rendered nothing and went on accepting the value. It now greys with the reason ⚑. Card: Raised is overridden in dark — a mode, not a switch — and Background role stays free, the cards being the items' geometry.
Avatars with no photograph show initials, and the two forms are not interchangeable No subject. A22 renders no person — no author, no member avatar, no initials in sixteen designs — so neither the two-initial form nor Ghost's one-letter form has anything to draw here. Recorded rather than skipped: a list the user types gets two initials, an author Ghost supplies gets one, and the two are never mixed inside one component.
The Remove button never greys out No subject of its own. 11 Reasons owns the category's only authored list; the Ghost-sourced lists in 9, 10, 12 and 15 have no Add and no Remove at all, so there is no Remove here to grey or keep.
A count that picks between drawn layouts is a named set, not a number picker One subject, and it stays as drawn. Cards across — Two · Three · Auto — is a named set and every value has a frame somebody has looked at: two of 636, three of 416, and Auto following Ghost's own count. It picks an arrangement, not a number of items, so it is not converted into a picker.
A design may declare the width below which its script runs No width declared. member-form runs at every width, so there is no boundary to name — and the no-JavaScript line already describes every width, not just the narrow one.
Ghost finding · the feature-image caption renders differently on the two Ghost versions No subject. This design reads no feature-image caption. Named for a builder who adds one: Ghost 6 quietly removes <em> and <strong> from a caption while keeping links and <b>; Ghost 5 keeps everything, so a caption that leans on italics gets them on one supported version and not the other.
Ghost finding · a comment count renders nothing at all without JavaScript No subject. A22 reads no comment count, ships no comment noun and labels no number — A28 owns that surface. Named because the shape matters: Ghost writes the number in with a script and prepends it to the noun, so a catalog string is the bare noun and never contains a number; the widget renders without JavaScript and its count does not.
The work list · a feed with nothing in it shows its designed empty state Not a feed, for the same reason as 10 Choice: zero newsletters is unreachable ⚑. At one letter one card sits at the grid's left with no stretch and the panel names 2 Card.

No arrangement moved on this frame, no control was added, removed or renamed, and no value, default, type scale, colour pack or spacing step changed. Left alone deliberately: every count-agnostic string in this library — nothing here writes a number of designs into any copy — and P0's per-prop mark allowlist, whose wording about a mark being absent from the toolbar rather than greyed is P0's text and is neither restated nor softened by the rule above, which governs a control switched off by another control.
