Change

Each value with the figure it replaced, on a line of its own: a glyph, a word and the previous number. The one design that reads prev, and the one where a stat is a comparison rather than a count.

Direction is carried by a triangle and a word, never by a colour. The packs supply one accent and no semantic pair, so green-up and red-down do not exist to be used — and a reader who cannot separate the two would be reading a section whose only signal is hue. The theme compares the two figures and does not subtract them: it will say a number went up, and it will not publish a difference nobody typed.

Direction is computed, and only when both figures parse. Separators, spaces, the prefix and the suffix are stripped and what remains is read as a number; if either side does not parse, the line reads “was …” with no glyph and no direction word. That is what makes “Sold out” against “240 left” safe: the section states the replacement without claiming which way it went. ⚑ Mine, including the four wordings. The four wordings are fixed and not editable: “up from”, “down from”, “unchanged from”, “was”. A site that wants “grew to” or “fell to” is writing a sentence, which is 11 Inline. The period is not named in the line — no “since 2025”, no “YoY”, no “vs. last year” — because the theme does not know the period. The site types it into the sub, once, for all four stats. ⚑ Mine. No difference is calculated. Not 8,400, not +25%, not a ratio: a figure the theme derives is a figure nobody checked, and rounding it is a second decision made on the site's behalf. A site that wants the delta types it as its own stat, with the label saying what it is. This is the same refusal 9 Bars made about normalising shares. ⚑ Mine. A stat with no prev draws no change line and nothing is substituted — no “new”, no dash, no “first year”. The label moves up 28 px, the values stay on one baseline because the value is first in the cell, and the row's height is the tallest cell's. With no stat carrying a prev no change lines are drawn and the cells are unchanged, with 1 Row advised in the panel.

The triangle and the word are both drawn in text-muted, the same as the label beside them, so a reader who sees no colour difference loses nothing. ACCESSIBILITY · ANNOTATED · DIRECTION THAT SURVIVES WITHOUT COLOUR OR SHAPE The direction is a word, so it survives every reading condition: greyscale, forced colours, a screen reader, and a printed page. The triangle carries aria-hidden="true" — “black up-pointing triangle, up from 33,400” is the glyph announced twice, and the word is the part that means something. ⚑ Mine. The stat is one <p> holding all three lines, so it announces as “41,800, up from 33,400, readers on the Thursday letter” — one string, in the order it is drawn. The change line is not a separate paragraph and not a <del>/<ins> pair: the previous figure is not deleted text, it is a fact about last year. Under and Beside announce identically, because the placement changes the layout and not the DOM. That is what makes the forced Under at ≤ 767 safe: a reader on a phone hears exactly what a reader on a desktop hears. Contrast: value 15.8:1 light / 15.1:1 dark; change line, glyph and label all 5.6:1 / 6.0:1 — one colour for the whole meta line, so no part of it is quieter than another. Link underline 3.3:1 / 6.3:1. In forced colours the triangle and the words take the system text colour and nothing is lost, because nothing was carried by hue. One tab stop. No motion. STATS · the item list · outside the design’s listStats is the P0·3 item list: Add stat arrives with content — value 100, label “What this number counts” — Remove is never disabled, drag to reorder, per-item content only. Per item: value ≤ 12 · prefix ≤ 3 · suffix ≤ 6 · label ≤ 60, and prev ≤ 12, a text field like value; note and share held. Value source: Authored · Member count · Paid member count. At Member count the value renders Ghost’s {​{total_members}} string verbatim — “1,200+” in, “1,200+” out, no maths and no formatter, which is the category’s own no-formatter rule — prefix and suffix are disabled and the label stays authored. {​{total_paid_members}} is offered only when the site has paid members enabled. A bound value can carry a prev: Ghost gives this year’s figure and the site types last year’s, and the direction is parsed from the two strings as usual. Eight is the ceiling of stats[], raised from six in this pass: “Eight numbers is as many as a reader holds in one look. A ninth is a table, and a table is a different section.” 3 Grid is the only design that draws eight; everywhere else seven or eight authored names it. Five to eight authored: this design draws its own count and 3 Grid is advised, and the change lines are not drawn there, because 3 Grid does not read prev.
EDITING · the P0 primitivesValue, prefix, suffix and label edit inline on canvas, selected where they are drawn rather than only in the repeater. The value raises no marks toolbar — it is plain text, so bold, italic and a link inside a figure are withheld rather than offered and refused. Eyebrow, title, sub, source and the link label take the P0·1 toolbar — bold · italic · underline · link, the popover carrying open-in-new-tab and rel nofollow · noreferrer · sponsored. A value bound to a member count is not inline-editable: clicking it says “Edit in Ghost”, because the figure is the site’s member list and not a word anyone typed here. prev edits inline where it is drawn, in the change line, and raises no marks toolbar either. The four wordings are not editable fields — they are theme catalog strings, so a non-English site translates them once rather than typing “up from” into every stat. sourceUrl and linkUrl open the Link Picker; the section link takes an optional P0·2 icon.
BEHAVIOUR · from the fixed registrycount-up, from the fixed registry, and only at Count up On. Its own degradation is the argument: “The final value renders as static text — it is already in the HTML before JS ever runs.” JS off, reduced motion and assistive technology all get the figure rather than the animation, and the module does not re-run on the way back up the page. Edit-safe: it does not run while the section is edited, so every frame here is still a resting state. At Count up Off — the default — this design declares no module at all: the direction is parsed before the page is served and the glyph is a static character. At Count up On the current figure counts and the previous one does not — a change line whose second number also moved would read as two live figures — and neither the glyph nor the direction word animates.
DATA · Ghost’s two member helpers · outside the design’s listTwo figures in A10 can come from Ghost, and both are public theme helpers: {​{total_members}} and {​{total_paid_members}}, each rendering a pre-rounded string. They are reached from the item’s Value source and not from a “Populate from…” panel — there is no list to populate. Everything else is authored in this section. Refused on record: a post count from a tag (a number nobody wrote and nobody checks), any admin-API figure — opens, revenue, growth — a live figure from a third party, and the four ornaments: sparkline, dial, donut, pie. 9 Bars’ single proportional bar is as far as A10 goes.
