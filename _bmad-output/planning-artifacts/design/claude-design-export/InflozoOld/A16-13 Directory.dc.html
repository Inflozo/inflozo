This design draws no form ⚑, declares no behaviour module, and has no delivery group — every row is a link. At one row the header row is removed and the table becomes a labelled pair ⚑, because a table header above a single row is a heading for nothing; the panel names 9 Slim Bar as the design for one address. A row with no note keeps its height ⚑ — the columns are a grid and a short row would break the alignment that makes a table readable.

THE DELIVERY GROUP · ABSENT HEREThis design draws no form ⚑, so the delivery rows are not shown, and the mailto: honesty fix does not reach it — every cell is already a real mailto: link. This is the design that works when the reader has no mail client, no script and the form service is down, which is why the form panels name it as the fallback A16 always has. The rows are kept on the section and return on switching.
EDITING · the P0 primitivesEvery visible text edits inline on canvas with the P0·1 toolbar — bold · italic · underline · link, the link popover carrying Open in new tab and rel nofollow · noreferrer · sponsored: the eyebrow, the heading, the blurb, the three column headers and every row’s label, note and address — click a cell and type ⚑. The field labels and the placeholders are edited by clicking them on the canvas ⚑ — this panel holds no label boxes. Nothing drawn here is Ghost-owned ⚑, so no line carries the “Edit in Ghost” lock — A16 reads only @site.title, and only as an aria-label fallback. Every URL field opens the Ghost-aware Link Picker. Buttons accept an optional icon before or after the label from the P0·2 Icon Picker with its size / colour-role popover, off by default ⚑. No fixed English visitor-facing string ships ⚑: columnLabels (“What it is”, “Use it for”, “Where it goes”) and every item string are authored fields with defaults, and “Sending…”, “Send another message”, the failed banner’s first line, “Email us at {address}” and the honeypot’s hidden label are theme translation-catalog strings.
BEHAVIOUR · from the fixed registryNone ⚑ — text and real links: mailto:, tel: and the social URLs. There is nothing to degrade, which is why the form panels offer this design as the fallback A16 always has. No module name is coined, and the contact-form registry addition the form designs ask for does not touch this one.
DATA · Ghost’s surface, and what A16 cannot readNothing is read from Ghost’s content API ⚑ — no Show ladder, no filter, and the P0·5 “Populate from…” panel is not offered anywhere in A16 ⚑, because no design reads a Ghost list. This design draws no action, so Member visibility is not offered ⚑ — recorded rather than invented; a members-only page is A32 Paywall’s ground.Ghost exposes no author emails to a theme ⚑ — the finding stands, and it is why this table cannot be generated from the site’s users: every row is authored.
