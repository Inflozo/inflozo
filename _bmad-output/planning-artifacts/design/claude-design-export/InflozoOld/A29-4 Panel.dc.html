WHAT THIS PANEL SETTLESReconciled. Padding retired into Vertical spacing — same three values, same ladder, so the row was a duplicate ⚑ — and the plane's fixed 44 × 48 inside is stated there. Eyebrow: Show · Hide added, the zero count string moved to the catalog, the Content group added, and Archive source recut as the Data group. Six controls of its own.The plane's internal padding is not a control. 44 × 48 is what makes it read as a plane rather than a box; exposing it invites 12 px, which is a border with a shadow ⚑. Padding controls the space around the plane, which is what the user is actually asking about.Flat is not a dark-mode control. Dark is always Flat because the warm shadow does not exist in dark — the hairline carries the plane instead. The control is for light pages that want a quieter head ⚑.The name ladder on the plane is one step down from the page ladder: a 68 px name inside a bordered plane reads as a poster, and this design is not that. 9 Big Type is.
