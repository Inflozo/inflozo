Stacked Masthead

Two rows: the masthead, then the nav. The publication gets a display moment at the top of the page, and the nav row detaches on scroll to become the sticky bar — which is where the reading-progress rule lives. The one design in A1 with a display moment: the wordmark is the section’s largest type, so nothing else in it competes.

The masthead scrolls away with the page; the nav row pins. The wordmark reappears in the pinned row at body size, so the site’s name is never off-screen.

A 2 px accent rule tracks reading progress along the bottom edge of the pinned bar. It is the second accent use in this section, and the last — the rule is off by default and only offered on post templates, because on a home page there is nothing to be a fraction of.

SPEC · A1·3 STACKED MASTHEAD · full text in “A1 Headers — Spec.md”
Content fields Adds the two A1 fields only this design and A1·15 use: tagline (text, opt, ≤ 48 chars) and dateLine (bool — renders today’s date in the site’s locale). Otherwise the shared list: logo, siteTitle, navItems (max 8 here — the row is wider), children, signInLabel, ctaLabel/ctaUrl.
Data Ghost navigation for the nav row; tagline defaults to Ghost’s site description and can be overridden. Empty nav → the rule pair and the nav row are both removed, leaving the masthead alone (never an empty ruled band). Reading progress needs a post context; on other templates the control is disabled with the reason shown.
Responsive · empty · a11y 1440–1024 as drawn. 1023–768 date + actions leave, nav row becomes a scroll rail. ≤767 wordmark 23 px, rail keeps two visible items, drawer holds the rest. a11y: wordmark is the site link, not an h1, on every template except the home page; tagline is a p, not a heading; the scroll rail is keyboard-scrollable and items are never clipped from focus.
