NO JAVASCRIPT · IDENTICAL · THE FORM IS A NATIVE POST ⚑
There is no themed submitting state ⚑. The form is a native POST, so the browser owns the wait: the button keeps its resting look and the page navigates. A spinner would need a module the registry does not have — the closest is member-form, which posts to Ghost’s members endpoint and is the wrong endpoint. That is a finding, not a new module.Wrong password is a fresh server render ⚑, not an inline check: Ghost re-renders private.hbs with its own error, the field comes back empty — Ghost does not echo a password — and focus returns to the field. The message sits above the label so a screen reader meets it before the input.The message is Ghost’s string and not a field ⚑. A design decides where it sits and how it is marked, and no control changes its words. It is drawn in the text colour on the plate with a hairline, never in red: the Paper pack has no error token, and inventing one would break in the other eleven packs.

The message takes a row of its own at the top of the box ⚑, ruled like the others, in the text colour. The box’s border does not change — an error is inside the box, not a property of it.

Which page this is
From the status code🔒
Read-only. Ghost decides — error-404.hbs at a 404 ⚑, error.hbs or error-5xx.hbs at a 500, private.hbs at /private/ ⚑ — and the section draws the matching copy set. One design, three pages.
What a 500 may ask Ghost for
Nothing🔒
Read-only. No {​{#get}​}, no navigation, no member state, no settings image ⚑ — a 500 may be the data layer failing, so every query is a second chance to fail. Static text, the site title and one link to /.
Navigation on this page
Set by the page🔒
Read-only. Full chrome on the 404 · title and one link on the 500 · none on the gate ⚑. A visitor at /private/ is not in the site yet, and nav labels describe a site they have not been admitted to.
Where the gate posts
Ghost’s /private/🔒
Read-only. A native POST to Ghost’s own route ⚑ — <form method="post"> with no drawn action ⚑ — Ghost supplies the destination. The wrong-password message is Ghost’s string, not a field; the design decides only where it sits.
EDITING · THE P0 PRIMITIVESEvery authored string edits inline on canvas with the P0·1 toolbar — bold · italic · underline · link, the popover carrying Open in new tab and rel nofollow · noreferrer · sponsored: heading, blurb, eyebrow, both action labels, linksLabel and the gate's field, button and helper strings. Ghost-owned content is never inline-editable ⚑ — the status code, Ghost's wrong-password string, post titles and excerpts, navigation labels and @site.title answer "Edit in Ghost" or show P0·1's lock pill. Every URL field opens the Ghost-aware Link Picker. The primary button takes the optional P0·2 icon — Before or After the label, always Small, always the label's colour, its Size and Colour rows hidden. WHAT THIS PANEL SETTLESFive controls, not six ⚑ — this design has no depth to offer (there is no fill and no shadow) and no alignment worth offering (a hairline box with centred text inside reads as a certificate). The brief’s floor is four, and dropping two rows that would only ever be set once is the point of a minimum.The URL in the row is a decision about error pages specifically ⚑. On a normal page a visible URL is noise; on a 404 the reader is lost, and “/archive/” tells them where they are being sent.Closest neighbour: 3 Card — set Recovery links = Plain list and the two differ only in fill and shadow ⚑, which is a real difference at rest and a thin one written down. The panel says so rather than pretending otherwise.Reconciled. Five controls: Eyebrow joins the five, and "Padding inside" is renamed Box padding ⚑ — it is a box-internal ladder, not the section's vertical rhythm, so it survives the duplicate-row rule under a distinct name while Vertical spacing in the trio owns the page's own 96 · 80 · 64. DESIGN PATCH PASS · 30 AUGUST 2026 · WHAT CHANGED IN 4 BOXED, AND THE RULE THAT REQUIRED IT
This design's own drawn search form is struck ⚑ — the field, its annotation, the Search on the 404 row, the search placeholder field, the two translation-catalog words and the read-only What search reaches row all go. The 404 renders the site header, so search there is the Headers category's Search control, and there is no search page for a form of A31's own to submit to. Controls of its own: 6 → 5. The gate's form no longer draws a destination ⚑ — no action attribute is drawn anywhere on the frame. Ghost supplies it, and a drawn one breaks Ghost's own return-to-the-page-you-asked-for behaviour. The field is still Ghost's own password helper, and the four gate states are untouched. Box padding keeps its name — the box's internal padding and the page's vertical rhythm are two different measurements, so the row stays in this design's own list under a distinct name while Vertical spacing in the universal trio owns 96 · 80 · 64. Recorded rather than silently kept. The no-JavaScript line, restated. This design contains no subscribe and no sign-in form, so the notice that replaces such a form does not apply here; the gate's password form is a native POST and works with JavaScript off. With the search field gone, the page is still pixel-identical without JavaScript ⚑. The build shape is ruled — 30 August 2026. Two templates: error-404.hbs, which Ghost permits helpers in, so the 404 keeps its whole chrome; and error.hbs for every other code, with no helper, no partial and no context — {​{statusCode}​} and {​{message}​} are the only dynamic values and every other word is hard-coded, the wordmark included. The publication still writes all of it in the editor.
