2 · Split Head

The head, the count and the house rules stand in a 320 px column at the left; Ghost's block takes the remaining 904. The rules stop being a line of small print and become a list you can read before you type.

This is the design for a publication that moderates. It is also the only design besides 6 Rail where the house rules are a list the user builds item by item, which is why the panel carries an item editor and the others do not.

DESIGN PATCH PASS · 29 AUGUST 2026 · WHAT CHANGED ON THIS FRAME, AND WHY
The count is drawn by Ghost's own script. {​{comment_count}​} renders a placeholder that Ghost's comments script fills, so with JavaScript off there is no number at all — not a zero, nothing ⚑. This design's no-JavaScript line is rewritten in the drawn spec below, and its accessible name no longer depends on the count. The comment box's colour is a setting inside Ghost. Inflozo does not change it, so the Block colour row is gone from the Data group and no design passes mode= any more. In its place a read-only row that links to the setting in Ghost ⚑. One hand-off phrase deleted. Both off → the design is 1 Rule is gone: with the head and the rules both off the column carries the count alone at 320, the block never widens, and it is still 2 Split Head — the panel may advise 1 Rule and never switches to it ⚑. The column's accessible name is the head, never the count. What did not change. The visual language, the type scale, the colour packs, the spacing system, every measure and this design's number. The sent, error and loading states on member forms still work — only the promise that they work without JavaScript was wrong.

THE WRITTEN SPEC · ALL TEN FIELDS
1 · Descriptor. The head, count and house rules in a fixed left column beside Ghost's block. The design for a publication that moderates and wants its rules read.2 · Structural descriptor. split · none · page · few · none · the head and house rules in a left column
Count few — the rules list is one to four items and is the one thing in A28 the user authors as an array. 9 Big Count is the other split · none · page and is separated on exactly this slot.3 · Archetype. split. One departure: it collapses at 834 rather than 767 ⚑, for the reason given on the responsive frame.4 · Responsive rule. 1440 320 · 72 · 904 on 1,296; heading 28, count 15 under it, rules 15 with 5 px bullets, top-aligned. 834 stacked at 754: head, count beside it, rules full width, 28 to the block, padding 80. ≤ 767 stacked at 350, count under the heading, 24 to the block, padding 64. Head column and Sticky head stop applying when stacked ⚑.5 · Content fields. headingText · rulesText (at One line) · rules[] 2–4 items, each 60 ch, authored and ordered ⚑ · closedNotice. From Ghost: {​{comment_count}​}, {​{#if comments}​}.
6 · Controls, in sidebar order. Heading · Head column (Narrow · Standard · Wide) · House rules (Off · One line · List) · the rules item list, P0·3 · Sticky head (On · Off). Four. Then the universal trio and the Data group.7 · Data. As 1 Rule. The count sits under the heading in the column and is not repeated anywhere else ⚑.8 · Empty state. House rules Off, or an empty list → the column is the head and count alone, 320 wide, and the block does not widen ⚑. Heading None with rules on → a column of rules with no head, which is drawn and is legal. Both off → the column is a count alone and it is still 2 Split Head — the panel advises 1 Rule and never switches ⚑ ⚑.9 · Behaviour module. none. Sticky head is CSS — position: sticky needs no JavaScript and declares no module ⚑. No-JS: the block is absent and so is the count ⚑ — Ghost's script draws the number, so the left column is a head, its rules and the <noscript> line, with no number and no zero (finding 3).10 · Accessibility. <section aria-labelledby> named by the head, which is an h2; the count is a <span> under it and is never part of the name ⚑. The rules are a <ul>, so a screen reader announces "list, 3 items" before the block ⚑. DOM order head → rules → block at every width.Flagged ⚑ 320 · 72 · 904 · top-aligning to the block's box rather than its editor row · collapsing at 834 · List as this design's default · the new-rule placeholder "Be kind" · the notice keeping the block's column · sticky off by default · removing the last rule setting House rules to Off · the count being Ghost's script and absent without JavaScript · the comment box's colour being Ghost's own setting.
