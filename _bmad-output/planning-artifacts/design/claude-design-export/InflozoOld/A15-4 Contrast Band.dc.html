4 · Contrast Band

One film on a full-bleed inverted band, the head above it in the carried colour, the meta line beneath in the band’s muted step. The same arrangement as 1 Player on a different ground.

It is the section for a film that has to interrupt the page — a trailer at the top of a landing page, the one film in a long article — where a change of ground does the work a bigger frame would otherwise have to.

PASS FIVE PATCH · 3 SEPTEMBER 2026 · WHAT CHANGED ON THIS FRAME, AND THE RULE THAT REQUIRED IT
What changed on this framePanel copy only. Where this frame enumerated Image focus’s values it now cites P0·9, which defines the control once and carries both axes — up and down, and side to side. The values are not restated here.
The rule that required itOne control name means one set of values. A private copy of a shared control’s values is the failure the rule exists to prevent, and A15 held one. Image focus is defined once, in P0·9, and it carries both axes — owner-ruled 3 September 2026, and the horizontal axis arrives with the same ruling rather than being drawn here.
Nothing was redrawnNo panel row was added or removed. Image focus has never been a row in this design’s control list — it is per film, reached from the Image Picker popover — so there was nothing on this frame to redraw, and the control count is unchanged. Ghost never sees it: the compiler resolves the hint, which is why it is a control and not a data binding.
No design total is written anywhereChecked, and nothing was added. No copy on this frame quotes a library size, in any form, and none was introduced by this pass.
