5 · Full Bleed

The film edge to edge at the viewport’s full width, square-cornered, with the head above it and the meta line beneath, both inside the page’s margins. The section has no ground of its own.

It is the section for a film that is the page — a title sequence, an aerial, anything shot to be seen large — and the one design in A15 where the frame is bigger than the reading measure by design.

DESIGN PATCH PASS · 29 AUGUST 2026 · WHAT CHANGED ON THIS FRAME, AND WHY
There is nowhere to upload to, so the Upload source is deleted. Ghost’s public interface has no media library a theme can read, Inflozo is not permitted to put files on a customer’s Ghost, and Inflozo’s own asset system handles images only. Every film in this design is a pasted URL ⚑ — a provider embed, or a media file already hosted on the customer’s own Ghost, which stays first-party and keeps its native <video controls playsinline preload="none" poster>. The ambient loop goes with it. The Playback row — Click to play · Ambient loop — is deleted from the panel: the loop had no source of files. Nothing autoplays anywhere in A15 again, and the reduced-motion registry addition the loop needed is withdrawn — the category is back to four findings. Nothing reads a duration off a file. duration ≤ 8 is typed by the author again. Patched 1 Sep 2026: nothing is fetched from a provider either — the title, the description and the poster are required fields the customer fills in. No poster, no title and no duration each close up exactly as drawn. Embeds are unaffected. YouTube, Vimeo and the audio providers keep this design, its facade, its click-to-load notice and their refusal to autoplay. No layout, measure, type size, colour or spacing changed on this frame ⚑, and the design’s number is unchanged.

PASS FIVE PATCH · 3 SEPTEMBER 2026 · WHAT CHANGED ON THIS FRAME, AND THE RULE THAT REQUIRED IT
What changed on this framePanel copy only. Where this frame enumerated Image focus’s values it now cites P0·9, which defines the control once and carries both axes — up and down, and side to side. The values are not restated here.
The rule that required itOne control name means one set of values. A private copy of a shared control’s values is the failure the rule exists to prevent, and A15 held one. Image focus is defined once, in P0·9, and it carries both axes — owner-ruled 3 September 2026, and the horizontal axis arrives with the same ruling rather than being drawn here.
Nothing was redrawnNo panel row was added or removed. Image focus has never been a row in this design’s control list — it is per film, reached from the Image Picker popover — so there was nothing on this frame to redraw, and the control count is unchanged. Ghost never sees it: the compiler resolves the hint, which is why it is a control and not a data binding.
No design total is written anywhereChecked, and nothing was added. No copy on this frame quotes a library size, in any form, and none was introduced by this pass.
