How to read this board

Every card is one story. A story moves left to right as it is built, and it comes to you once, in the gold column.

Backlog
Not started. Its spec (the written plan for the story) has not been written.
Ready
The spec is written and waiting to be built.
In progress
Being built now.
In review
Being checked against the real services, then deployed. Nothing for you to do yet.
Deployed, your test
The gold column. Live on the real site and waiting for you. Open the card, follow the numbered steps, and say what you saw in chat. A red stripe means you reported issues and they are being fixed. A story with no screen skips your test: say "done" in chat and the Record prompt closes it.
Done
You accepted it.

The phases. Create (write the spec) → Build → Review (check it on the real services) → Deploy (put it live) → Test (you) → Done. If your test finds issues: Fix → Review → Deploy → Test again, inside the same story.

The prompts. Each card carries one Copy prompt button, for the phase on its badge; Details shows every phase's prompt. Paste it into a Claude Code chat exactly as copied, top to bottom — some begin with a /command, some do not.

Reload. Reload this page whenever a session says it has saved. Every save is a commit shaped Story E.S - Phase - one line, this board is rebuilt from those commits, and a story's history is its commit list.

Questions for you. The inbox in the top bar lists every open question across every story. Each is plain English with numbered options and one marked RECOMMENDED; answer in chat by number.

Waits for. In the two library epics the stories run one at a time behind your category gate, so only the first open one carries a prompt; the rest say which story they wait for.

Keys. / focuses the search, Esc closes a panel. The ticks on a test script are stored in this browser only; your verdict still goes through chat.
