What the picker never offers you

A design whose bindingContext does not match this template is never shown — not greyed, not shown-and-refused (FR-D12). And a second Post Content section is refused at placement, with the reason, because the layout already prints the article (ruling R-37).

ⓘOn a Tag archive the picker never lists a design that binds a single post. It is not in the grid at all — showing it and refusing it would teach the user nothing.
!This layout already prints the article. A page can have one Post Content section, so this one was not placed.
