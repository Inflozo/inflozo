The card dropdown — every Koenig card, in Ghost’s order

Colour controls are never offered for header, signup and CTA cards. The post author sets those inline in Ghost’s editor, and a control that silently loses to an inline style is worse than none. The order the frame claimed as Ghost’s was not, until the 2026-09-04 export (A7 item 15): it now follows the editor’s own menu, read from the koenig-lexical bundle on 5.130.6 and 6.58.0 — Video before Audio, Embed last, and slot 8 is Email call to action, the email-only card that renders nothing on the web (MEASUREMENTS §35b), which is where the NO COLOUR CTLS mark sits; the web Call to action keeps its own entry and its panel.

S14c · RESET TO GHOST DEFAULT — THE CONFIRM · PER CARD, NEVER WHOLE-SET · DETAIL 520
Reset Callout to Ghost's default? Removes your 3 changes — colours, emoji and emoji size — everywhere callouts appear. Posts keep their content.
Cancel Reset card
THE SENTENCE NAMES THE COUNT AND THE CHANGED CONTROLS · "POSTS KEEP THEIR CONTENT" IS ALWAYS THE SECOND SENTENCE — THE FEAR TO ANSWER · RESET CLEARS THE CUSTOMISED BADGE IN THE DROPDOWN AND THE LEFT RAIL · UNDOABLE FROM THE EDITOR'S UNDO STACK, SO THE CONFIRM IS ONE STEP, NOT TWO

Reset is per card and scoped in words — the treatment choice and other cards' overrides are untouched. There is deliberately no "reset all cards": twenty decisions removed by one click is a footgun with no matching user intent.

C1c · the card panels

C.1 · THREE PANELS IN FULL

Simple, complex, structural

Callout is a box treatment, Bookmark is a layout, Gallery is a set of proportions. Each sits beside the card rendered between real paragraphs, because a card looks different alone than it does mid-article.

Notes. This is the panel the earlier draft got wrong. Ghost's callout carries an emoji in .kg-callout-emoji, chosen by the writer — so the only honest controls are show, hide, and where it sits. There is no icon option and no colour picker: the writer picks from Ghost's nine, and the strip above the canvas switches which variant you are looking at while you style them all. The accent variant fills with the site's accent colour, which is where the Style Pack reaches this card.

Notes. Ghost's bookmark markup nests title, description and a metadata row beside a thumbnail inside one anchor, which is why position is a flex decision the theme can make freely and the row list is a set of visibility toggles rather than a density preset. Colour is absent on purpose: the card has no colour of its own in Ghost's CSS, and giving it one is how a page ends up with six card colours.

Notes. The badge on the canvas says 2 rows from Ghost because that is the honest division of labour: Ghost's script groups the images and sets each row's flex ratios, and the panel only touches what sits between and around them. Uniform is the one control that fights Ghost — it forces equal row heights and crops to get them, so the option says so rather than hiding it behind a tidier word.
