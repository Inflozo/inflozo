The frame sends people to fix something that cannot be fixed

B16 says “your integration key is missing the settings permission … Fix the key.” Integration tokens never carry setting: edit — Ghost’s allowlist binds them and there is nothing to grant. A staff token carries a user_id, skips the allowlist entirely, and an Administrator or Owner holds setting: all. So the cause becomes “Uploading a routing file needs the site Owner’s Staff Access Token, and this project doesn’t have one”, and “Fix the key instead” becomes “Add the token instead”.

And the hard-coded menu path has to go

Step 2 says Settings → Labs. Ghost 6.58.0 has no Labs page — no settings/advanced, no settings/labs, and its export UI sits behind a lab flag (MEASUREMENTS §33, executed 2026-08-31). The card must describe what the customer is looking for and link to Ghost’s own help for the version Inflozo detected at connect.
