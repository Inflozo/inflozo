What it does, and what the frame keeps

Drawn by prompt A3 in the 2026-09-04 export. Before every deploy after the first to a given site, Inflozo reads the live theme and compares it against what it last deployed there; if anything differs, the deploy stops. Rows are grouped Changed / Added on your site / Removed from your site and — critically — each is named by the user’s own layer name (Home hero, Latest issues, Three Column footer) with the raw filename only as small mono text beneath; a file Inflozo never wrote is named as exactly that. Never a raw path as the primary label. Two actions besides Cancel: Download the live theme first, offered before the destructive one, and Overwrite and ship anyway — a deliberate choice, so ink and not danger.

It fails open, and it never asserts drift without two manifests

Where the Staff Access Token is absent it cannot read the live theme, so it shows a single sky information row inside the pre-flight list — “Couldn’t check whether your live theme changed … Shipping anyway” — and the deploy continues. A layer rename produces no drift at all, so the list never shows one: nothing on the live site changed, only a filename Inflozo chose.
