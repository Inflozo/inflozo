The &ldquo;one step left&rdquo; card, when custom templates were emitted

A card on the success state, not a modal that must be dismissed to reach the confetti. The deploy succeeded. A project whose deploy emitted no custom template never sees it — which is every starter’s first deploy, so the confetti stays clean. It is drawn as B19, on a mechanism FR-I1 forbids.

The confetti fires on the first deploy that makes the site LIVE

A deploy-only ends on Deploy Uploaded, not here. “Live! Your site just got gorgeous” would be false on a theme nobody is serving — the canonical string is what settles it.
