Three things both frames get wrong

FR-C8 needs three credentials, not two — the Staff Access Token is addable and removable at any time, and each credential is shown present or absent with what it enables, never as an error badge. B20 invents grantable scopes: Ghost fixes what a Custom Integration token may do, so the missing capability is the token, not a permission — there is nothing to grant. S11d draws the API URL as an editable field: the site URL is immutable, a domain move is disconnect + reconnect, so the affordance is absent rather than present-and-refusing.
