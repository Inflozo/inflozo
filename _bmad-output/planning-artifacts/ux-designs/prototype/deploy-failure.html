S8 Deploy.dc.html — S8d′ EXPERIENCE.md § IA → Deploy · § Voice and Tone (errors are human and name the fix)
Never “An error occurred.” The sentence names what happened in the other party’s terms and the button is the fix. But the cause this frame names does not exist. An Admin API key never expires — the api_keys table has no expiry column (read in source, Ghost 6.54.1 core/server/data/schema/schema.js) and docs.ghost.org/admin-api says the key can be regenerated any time; the only thing that expires is the five-minute JWT Inflozo signs with it. A key that was regenerated, or whose integration was deleted, answers 401 Unknown Admin API Key (executed against T1 6.58.0 and T3 5.130.6, review 2026-09-03). The sentence becomes “Ghost said no — this Admin API key no longer works. It was regenerated or removed in Ghost Admin. Paste the new key.” The frame’s text is prompt A7’s; it stays as drawn here. A deploy failure is one of the five product emails (FR-P1), and it is the only deploy outcome that sends one — uploaded-not-live sends nothing, because nothing failed.
