Staff Token Offer

Step 2 of the six-step first deploy. “One more step unlocks a safety net — a copy of your current theme before we replace it, plus a check that nothing else has changed it.” Then, quieter: this is a full-Administrator credential and can only be created on the site Owner’s own account. Two plain buttons, side by side, the same weight — “Add the token” and “Not now”. Not now is not a small link. Zero occurrences of “Staff Access Token” exist anywhere in the export.

Not drawnThis surface has no frame in the export. Appendix A prompt A1 (frames D1b, D1c) will draw it; it has not been run.

Nothing is drawn here on purpose. A picture invented in this file would be a second interface vocabulary beside the export’s, which is the one thing R-74 forbids. What the prompt must produce is described below and in EXPERIENCE.md Appendix A.

Declined — acknowledged once, then never raised again

It names exactly three costs — no snapshot, no drift check, manual routes upload — and closes with “You can add it any time from Manage keys.” Nothing implies the user has done something wrong. And the multi-site operator working on a client’s site cannot comply at all: they are not the Owner. This is not a degradation for them, it is the path.
