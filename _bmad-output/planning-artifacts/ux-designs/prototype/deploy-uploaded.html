Deploy Uploaded

The other ending, reached deliberately: the user picked Deploy only at step 1. Sky, not danger; the same card as Partial Success, the same rail state, the same two buttons — only the sentence changes, because only the cause changed. “Uploaded. Not live yet.” No confetti: the one confetti moment is the first deploy that makes the site live, and this one deliberately did not.

Nothing is drawn here on purpose. A picture invented in this file would be a second interface vocabulary beside the export’s, which is the one thing R-74 forbids. What the prompt must produce is described below and in EXPERIENCE.md Appendix A.

It is one state with two causes

Deploy Uploaded and Partial Success are the same state reached two ways, and the history row is identical for both — status uploaded, activated false, no active badge, Re-activate. Neither sends a deploy-failure email.
