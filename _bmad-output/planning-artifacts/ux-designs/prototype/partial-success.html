Partial Success

Upload succeeded, activation failed. This is a partial success, not a failure — sky, not danger, and not the S8d′ failure treatment. “Your theme is on your site but isn’t live yet.” The step rail shows Ship complete and Live incomplete.

Not drawnThis surface has no frame in the export. Appendix A prompt A2 (frames D2e, D2d) will draw it; it has not been run.

Nothing is drawn here on purpose. A picture invented in this file would be a second interface vocabulary beside the export’s, which is the one thing R-74 forbids. What the prompt must produce is described below and in EXPERIENCE.md Appendix A.

Six things follow from calling it a partial success

1The artifact is retained like any successful compile, and appears in history without an active badge.
2The theme name freezes, because the name is claimed on the site the moment a theme lands there.
3The drift baseline does not move — FR-J16 compares against what Inflozo last put live.
4“Never leaves a partially active theme” is unaffected — the site’s active theme is still the previous one.
5The user is told plainly, with a re-activate action, because “failed” would be wrong and silence would be worse.
6It sends no deploy-failure email.
