And its copy is wrong in the way that wastes an afternoon

S8a′ says “download your theme and upload it in Ghost Admin”. Starter’s customThemes limit forbids custom themes in Ghost Admin too — it is a plan limit, not an API limit, so the manual route does not exist either. The zip still downloads on every plan (FR-J12); what the copy must say is where it can be installed: a self-hosted Ghost, or a Ghost(Pro) plan that allows custom themes. B15 already gets this right.
