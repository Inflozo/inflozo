Appendix A — the Claude Design prompts

These draw the parts of Inflozo's own app that Claude Design has not drawn yet, and correct the frames it drew wrongly. They live in the UX spine, EXPERIENCE.md → Appendix A, and this page lifts them from it word for word. Paste each session's prompts into one Claude Design chat, in the order shown. Tick a card when you have run it. Export the whole project once, after Session 2, then run the runbook once. Progress is stored in this browser.

Running any of these produces a new export, which replaces the repository's copy. Two edits live in the repo rather than in Claude Design — the count-agnostic marketing copy and P0's per-prop mark allowlist — and a re-export loses them by construction. Follow the export runbook on the build board afterwards: tools/reapply-export-edits.py, then tools/verify-design-pass.py, then the derivations, then tools/doc-audit.py --check twice. The build board is BUILD-BOARD.html; the runbook is the numbered list at its top.

They can be run as two Claude Design sessions — A7 together with A8 (both correct or extend the editor's existing frames and share the focus-ring token), then A1 to A6 — and the export runbook above runs once, after the last session — one export of the whole project, dropped into the export directory, is enough; nothing in the repository needs the export between the two sessions, and the runbook is the same work however many prompts preceded it.

Every session must observe: A literal Ghost Handlebars expression must be written with zero-width entities. A bare {{ … }} is a Claude Design value hole and renders EMPTY.
