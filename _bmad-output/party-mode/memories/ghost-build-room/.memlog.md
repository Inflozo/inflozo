## 2026-08-20 — Round 4 security stress test (four Ghost-specific attacks)

- (constraint) Ravi, flat: **there is no scoped Ghost integration.** An Admin API key is `kid:secret` minting a JWT with `aud:/admin/`; Ghost verifies the signature, not the intent. No scope claim, no read-only integration exists. So P8's four-write allowlist is a real invariant about *Inflozo's behaviour* and not a boundary on the *credential*. Executed both majors: members incl. email, users, settings, POST /posts all 200/201.
- (decision) AD-10 must state the credential is all-or-nothing and name its compensating controls: the decrypt chokepoint (holds), key rotation (`admin_key_rotated_at` exists and nothing writes it — "that column is a confession"), and logging on the proxy (does not exist; Murat: detection time on credential misuse is currently unbounded).
- (question) Sally: Ghost offers no narrower key, but the *consent screen* can still say plainly that connecting hands over the subscriber list. Architecture is honest in the docs and silent in the UI. P3 expose-deliberately.
- (constraint) Escaping is a CHARACTER control; a URL scheme is a SEMANTIC property. `javascript:alert(1)` contains nothing to escape and survives every escaper intact. The Conventions row scheme-validates **Ghost-sourced** values only; the reasoning error was concluding user-typed values are therefore safe. The user is also a stranger to the visitor.
- (constraint) **The helper-argument breakout is Handlebars source built by string concatenation** — `{{img_url ${path} size="${arg}"}}`. Ravi: same class as SQL injection by concatenation. AD-5 made user text un-mustache-able and then the compiler generates mustaches from design-controlled strings by templating.
- (constraint) **AD-2 "the library is data, never code" is false twice**: `behaviour.js` is code, and `design.json` binding strings compile into template *source*. The second is new. D13's CI lint (the control for actor C) is unbuilt.
- (decision) Reframed by Ravi and it changes the priority: the *malicious* author is rare, the **typo** author is Thursday — `size:800px` instead of `size:800` emits a broken mustache and gscan blames the customer's theme. Same root cause: interpolating instead of parsing. Fix is a correctness fix and a security fix at once, which is also how to justify it.
- (constraint) Ghost's `accent_color` validation is "a regex that got lucky twice" — rejects `background:url(https://…)`, accepts `#fff;background:url(x)`. Decision B itself is sound (the per-tag compile-time alternative genuinely rots when the owner adds a tag); the wrong part is the *assumption underneath* it, that the bound value is a colour.
- (constraint) Murat's structural point: the accent_color check **cannot live in the FR-J17 gate** — the gate sees `style="--tag-accent: {{accent_color}}"` and correctly passes it; the value arrives at runtime on the customer's site after every gate has run. Winston: a data-plane risk in a system whose entire quality apparatus is a build-time gate. **This architecture has no home for that category of check.**
- (constraint) AD-21's iframe: Ghost data is controlled by the customer **or anyone who has ever held a Contributor/Author/Editor account on that Ghost** — an Author can set a title, excerpt or tag name. So the threat is not self-inflicted; it is a staff-account holder attacking the *owner's Inflozo session*. Same origin means anything executing there reads localStorage (session token), calls Inflozo's API as the owner, and reads the IndexedDB journal. `frame-ancestors 'self'` governs who may embed the frame and nothing about what runs inside it.
- (event) The moment of the session: Amelia pointed out `marks[].href` has no scheme check and **both renderers call `marks.ts`** — so the `javascript:` finding is not merely a visitor problem, it is a same-origin `javascript:` URL in the owner's authenticated session. Ravi stopped and made her repeat it. The iframe risk and the href finding are the same finding.
- (decision) **The unifying frame, Murat's wording, and it is what should reach Umang:** every finding tonight is *a value crossing from an untrusted source into a sink that interprets it, at a place where the only control was escaping.* Not four bugs — one missing idea, four times.
- (decision) Winston: there is **no AD for that idea**. AD-5 is it applied to braces; AD-4 is it applied to marks; both are instances of a rule nobody wrote down. Ravi: "Then write it down. That's your thirty-sixth." → proposed **AD-36**.
