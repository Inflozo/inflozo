## Goal

A user ships. The project compiles — purely, from what it is handed — into a real, hand-editable Ghost theme that passes gscan 0 errors / 0 warnings on both specs and FR-J17's quality gate; it uploads to the customer's own Ghost through the Admin chokepoint, activates (or waits, on purpose) and rolls back in one click — with the previous theme archived first, drift caught before it is overwritten, `routes.yaml` uploaded and read back, and every theme setting, promoted control and translation emitted. The compiler is new (`packages/theme-compiler` is a one-line stub today) but its engine is not: it assembles what Epic 4's theme emitter and Epic 6's token block already produce. The epic also builds compile CI over the whole library and the canvas-vs-real-Ghost harness that must exist before E9 opens, and closes on the E4/E7 joint gate. **Exit:** the pilot project deployed and rolled back on all Ghost deploy targets; routes round-trip verified by byte comparison; the joint gate green. Every Ghost check runs on T1 alone (R-238); each Ghost 5 half waits for DW-326's pass at Story 15.7.

## Technical Decisions

- **Functional core (AD-1, AD-14):** `compile(doc, library, stylePack, routes, assetBytes, settingsSnapshot) → fileTree` is byte-deterministic, takes the world as values the shell fetched, and also returns which design stylesheets each template reaches (the strip's and the CSS budget's one fact). The core bans clocks, randomness, I/O and the locale readers (`localeCompare`, `toLocale*Case`, `Intl.*`) — the slug function included.
- **Brace-safe emission (AD-4, AD-5):** user text is text-plus-marks serialized by `marks.ts` and spliced after `outerHTML`, braces as numeric entities; a mustache never abuts `}`; `PAGE_NUMBER_HBS` is the one unescaped constant. **AD-36:** every new sink — a `routes.yaml` field, a translation override, a promoted setting reaching a URL — is parsed and rebuilt, never interpolated, with an inert-and-legitimate pair in `ad36.test.ts`.
- **AD-3, AD-37:** a control is one root attribute (promoted: `data-{control}="{{@custom.key}}"`, stylesheet unchanged); the only inline `style` is one custom property from bound Ghost data, asserted by FR-J17; a placed design is the design that renders, and adjacency (`data-needs`) is answered from the placement list at build.

- **AD-11, AD-13:** compile, gate, zip and upload are one function invocation (300 s, memory per AD-11); the zip streams server-to-server, and export and snapshot downloads are short-lived signed URLs, never a response body.
- **AD-10, AD-19, AD-20, AD-24:** Admin calls go only through `apps/web/server/ghost-admin/*` (`ADMIN_WRITES`, an audit row per call); upload-and-activate holds `pg_advisory_xact_lock` on the site; one `deploy_jobs` row from `queued` (`stage` is progress, `deploys.status` the outcome, an infrastructure failure retried once); one envelope `{ code, message, detail?, action? }`.
