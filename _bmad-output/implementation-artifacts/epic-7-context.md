## Goal

A user ships. The project compiles — purely, from what it is handed — into a real, hand-editable Ghost theme that passes gscan 0 errors / 0 warnings on both specs and FR-J17's quality gate; it uploads to the customer's own Ghost through the Admin chokepoint, activates (or waits, on purpose) and rolls back in one click — with the previous theme archived first, drift caught before it is overwritten, `routes.yaml` uploaded and read back, and every theme setting, promoted control and translation emitted. The compiler is new (`packages/theme-compiler` is a one-line stub today) but its engine is not: it assembles what Epic 4's theme emitter and Epic 6's token block already produce. The epic also builds compile CI over the whole library and the canvas-vs-real-Ghost harness that must exist before E9 opens, and closes on the E4/E7 joint gate. **Exit:** the pilot project deployed and rolled back on all Ghost deploy targets; routes round-trip verified by byte comparison; the joint gate green. Every Ghost check runs on T1 alone (R-238); each Ghost 5 half waits for DW-326's pass at Story 15.7.

## Requirements & Constraints

- **Assembly never parses Handlebars (7.1, FR-J1).** Sections are walked as annotated HTML, values substituted, block helpers injected as comment markers, serialized with `outerHTML`, and markers unwrapped before expression tokens resolve in a final pass; user content ships inert, and compile is a pure function of what it was handed (AD-14).
  - **Epic 4 (built):** the walk, both emitters and the one serializer are `packages/section-runtime` (`core.ts`, `marks.ts`) — expression tokens and user-text markers are C0-control-delimited, resolved in reverse insertion order with the unwrap inside the loop, user text substituted last in one pass (MEASUREMENTS §14b); a design's own comments are dropped before the first token (DW-159); `agreement.test.ts` and `ad36.test.ts` hold it in `pnpm check`.
  - **R-238 (the T3 incident, 2026-10-04):** never emit a Handlebars expression inside a `{{#get}}` filter — CVE-2026-22594's vector, refused at emission (`ad36.test.ts`).
  - **Story 7.1's Create (2026-10-05):** `compileTheme(doc, input)` in `packages/theme-compiler` takes templates by file (`default.hbs` is the site doc; 7.18 maps keys with `fileOfKey`), the library as a function, the pack, the asset map, the strings and `postsPerPage`, and renders each visible instance through `renderTheme` with one shared `UserText` (a secondary feed through `feedQuery`; `designate` stays 7.3's). Two new AD-36 sinks: the layer name inside the boundary comment drops braces and C0 characters (executed: an unsanitized `--}}` turns the rest of the name into live Handlebars), and `data-partial` refuses Ghost's own partial names (`content-cta`, `gift-toast`, `navigation`, `pagination`, `recommendations`, read in both majors' `helpers/tpl/`). D13's design lint is built (`control-character`). Product code may not import `handlebars` or `prettier`; a test may parse output with handlebars 4.7.9.
  - **Story 7.1's Dev (2026-10-05):** built. `compileTheme` is `packages/theme-compiler/src/compile.ts`, `partialSlug` and `claim` are `slug.ts`, and `tools/pilot-theme.mjs` is the five-pilot project CI (`check-snapshots`) and the T1 recorder (`record-theme-assembly.py`) both compile. `Tokens.put` takes a marker's role (`open` · `else` · `close` · `block`), and the one shared `UserText` captures each prop's definition at put — before this, a shared instance read its own (empty) schema and a rich text prop lost its marks. `isSiteFooter` lives in `placement.ts`.   - **Story 7.1's Create (2026-10-05):** the theme serializer formats over the DOM while every expression is still a token.

## Technical Decisions
